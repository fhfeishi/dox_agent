## 中文摘要

场景识别算法作为机器人场景感知和环境理解的首要环节，是机器人认知场景中物体、智能人机交互的重要支撑技术。相对于小范围、结构固定的作业场景，机器人识别系统在面对场景动态变化大且未知、识别任务非固定等问题时，仍存在实时性、可迁移性等方面的挑战。为此，本项目拟研究使机器人在复杂动态场景中实时可迁移地执行非固定场景识别任务的关键技术，从而提高识别系统的实时性和可迁移性。在场景语义描述方面，拟构建多尺度轻量型卷积神经网络的场景深度描述方法，实现场景图像的全局和局部特征提取。在此基础上，拟利用各场景任务间的自表达特性构建模型知识库，实现基于任务自表达的增量式终身学习模型。优化上，利用凸估计实现对连续场景识别任务的优化，同时进一步实现对所提算法的技术验证。通过本研究，对建立面向机器人的统一、有效的终身场景识别算法框架奠定了理论基础，同时对机器人终身认知研究及其实际应用具有重要推进作用。

## 英文摘要

The scene recognition algorithm, as the primary link of robot scene perception and environment understanding, is an important supporting technology for robots to perceive objects and intelligent human-computer interaction in the scene. Compared with the small scope and fixed structure of the work scene, the robot recognition system still faces challenges in real-time and transferability when encountered that the scene dynamic change is large and unknown, and the scene recognition task is not fixed. To this end, this project intends to study the key technologies that enable robots to autonomously perform non-fixed scene recognition tasks in real-time and transferability for the complex dynamic scenarios, thereby improving the real-time and transferability of the recognition system. For the scene semantic description, a multi-scale lightweight convolutional neural network scene description method is proposed to realize both global and local feature extraction of scene images. Based on this description, this model is planned to use the self-expression property between tasks in each scenario to establish a model knowledge library, and implement an incremental life-long learning model based on task self-expression. For the optimization, a convex estimation is used to optimize the continuous scene recognition task, and the technical verification of the proposed algorithm is further realized. Through this research, it lays a theoretical foundation for the establishment of a unified and effective framework for lifelong scene recognition algorithms for robots, and has an important role in promoting the study of robotic lifelong cognition and its practical applications.

## 结题摘要

  本项目针对复杂动态工业或移动环境中实时可迁移地执行非固定场景识别任务的需求，旨在满足模型收敛率的基础上，建立基于终身学习的机器人场景识别技术，本项目的主要研究内容如下：.  在理论研究方面，本项目在将熟知的自动编码器体系结构扩展到终身学习框架，并通过稀疏约束进一步保持识别任务间关系，在大幅提高任务学习效率的同时保持模型的识别精度。为快速学习多个新任务，我们在本研究中提出基于表达任务选择的终身机器学习，并给出上述机器学习模型关键技术的收敛性分析。.  在实际应用方面，本项目将部分终身学习成果和实际视觉场景应用相结合，1）针对机器人目标感知中数据难以标注的问题，构建面向机器人无监督目标感知的终身机器学习算法，实现对新无监督感知任务的快速学习；2）针对机器人无监督目标感知时的多模态融合问题，提出一种面向机器人目标感知的终身视触融合谱聚类算法，实现多模态数据下无监督目标快速学习和感知；3）针对多视角人类行为识别问题，将连续学习和终身学习应用于人类行为识别领域，进而克服已学行为的灾难性遗忘难题。.  上述研究成果已经发表论文21篇，其中包括SCI论文16篇，EI论文5篇，其中包括IEEE Transactions论文13篇（人工智能顶级期刊IEEE Transactions on Pattern Analysis and Machine Intelligence 论文2篇），国际模式识别知名期刊Pattern Recognition 1篇，机器人顶级会议IROS 2篇。同时申请人获得国家自然科学基金面上项目的连续支持。
