## 开始前

1. 用 `bash launch.sh`（或 Windows 的 `launch.cmd`）启动，用 admin 账户登录。
2. 准备计时；任务卡只写目标，不写操作步骤。做的过程中想问“该点哪里”时，记一次“求助”，再继续。

## 任务卡

**任务 A：资料整理到对比报告**

> 新建一个资料库，名称自定，把 `资料包/` 里的 7 份文件全部导入。弄清哪些文件没能正常入库、为什么。
> 然后比较“柔性抓取”和“示教学习装配”这两个项目在研究方法和已取得成果上的差异，得到一份写明出处的对比结果；
> 打开其中一处引用的原文看一眼，再回到结果。最后把这份结果保存到报告中心，并导出 Word。

**任务 B：申请书形式审查**

> 用“通用形式审查示例”模板，对 `申请书/` 里的申请书做一次形式审查。
> 从审查报告中找出必须修改的问题，说出各自要怎么改；最后下载 Word 版审查报告。
