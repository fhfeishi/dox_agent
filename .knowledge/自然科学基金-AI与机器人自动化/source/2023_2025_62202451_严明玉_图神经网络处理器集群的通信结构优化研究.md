## 中文摘要

超大规模图神经网络（GNN）被认为是推动“认知智能”发展强有力的推理方法。与此同时，超大规模也意味着GNN单节点处理器算不下，存不下，面向GNN设计专用处理器集群势在必行。然而，集群的通信结构面临着GNN特有的不规则粗粒度通信行为，导致网络冲突多、重复通信多、通信带宽需求高等严峻挑战。..本课题将围绕着GNN处理器集群的通信结构设计开展如下研究：1）传得快---研究通信规则化以增强通信可预测性，从而实现高效通信调度规避网络冲突，减少数据的传输时间；2）传得精---研究基于图顶点映射和通信系统的实时状态，动态构建广播域和选定广播节点对共享数据广播，从而高效减少重复传输；3）传得少---研究路由中对顶点数据进行归约并复用归约结果，从而减少数据传输和降低通信带宽需求。通过以上研究，本课题旨在提高GNN处理器集群的通信效率，为GNN处理器集群的通信结构设计与优化提供新思路。

## 英文摘要

Very large-scale graph neural network (GNN) is considered to be a powerful reasoning method to promote "cognitive intelligence", but existing single-node GNN processor cannot efficiently perform such applications. So the GNN processor cluster has emerged as the times require. However, the communication architecture of cluster is faced with severe challenges deriving from the irregular and coarse-grained communication behavior peculiar to GNN, resulting in more communication conflicts, more repetitive communication, and higher communication bandwidth requirements. ..This project is aimed at the communication architecture optimization of GNN processor cluster, and carrys out the following research contents: 1) Fast transmission --- research on communication regularization to enhance communication predictability, so as to achieve efficient communication scheduling to avoid transmission conflicts and reduce data transmission time; 2) Canny transmission --- based on graph vertex mapping and real-time state of communication system, dynamically build broadcast domain and select broadcast nodes to broadcast shared data, so as to effectively reduce repeated transmission; 3) Less transmission --- study the reduction of vertex property data in routing and reuse the reduction results to reduce data transmission and reduce communication bandwidth requirements. Through the above research, this project aims to improve the communication efficiency of GNN processor cluster and provide new ideas for the design and optimization of the communication architecture of GNN processor cluster.

## 结题摘要

图神经网络是实现认知智能的关键技术，其大规模执行依赖多节点集群，而聚合阶段的不规则、高并发通信成为主要瓶颈，引发网络冲突、数据冗余和带宽压力。优化处理器集群通信结构对提升系统效能、推动大规模图智能应用具有重要意义。..项目围绕提升集群通信效率这一核心问题，以“传得快、传得精、传得少”为目标，开展了系统性研究。具体包括：1）针对通信不规则性导致的冲突问题，提出耦合隐式同步的主动分轮执行机制，通过计算与通信的解耦及结构化重排，将动态依赖的通信模式转化为可预测的分轮规则通信。2）针对邻居顶点数据的冗余传输问题，提出基于动态广播域的分散式广播机制，能依据实时数据依赖关系动态构建通信域并选择广播节点，实现共享数据的精准传输。3）针对高维数据带来的大通信量问题，提出路由中即时归约与结果复用策略，允许在传输中间节点提前进行归约计算，并复用中间结果以压缩数据传输总量。..原型验证表明，所提机制效果显著：基于分轮执行构建的MultiGCN系统相比同类方案实现了4–12倍加速；动态广播机制在8×8系统上为MultiGCN带来平均1.17倍额外加速，并减少4%网络传输；归约复用机制实现平均1.52倍加速。集成所有机制的原型系统相比其他多节点系统实现了6.6–19.8倍加速，相较多GPU方案达4.13–13.2倍加速。..研究形成了面向GNN处理器集群通信的“规则化、精简化、归约化”系统优化方法，产出CCF A/CCF B/SCI论文16篇、国家发明专利6项，培养博士4名、硕士4名，项目负责人入选北京市科技新星、中国科学院青促会及CCF青年人才发展计划。
