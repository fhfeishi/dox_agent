## 发现与修复

1. 单库请求绕过 KnowledgeGroup，引用 corpus_id 为空，三个/十四个预览分别全部 404。统一单库和多库的来源身份链路，删除单库捷径。
2. 补检合并两轮文档，突破预算；覆盖判断拿完整主题与分词集合直接比较。改为统一分词检查，新一次检索本身包含原问题，不再合并旧结果。
3. 长报告耗尽上下文，后续项目只余标题，导致模型称原文为空。剩余上下文按剩余报告分配，明确标记截断。
4. 多主题查询倾向相同主题。预算内选择互补标题主题；过滤问题中的通用指令词，修正尾部助词切分。
5. 对话年份未成为筛选条件，模型自行改成结束年口径。按项目区间相交筛选，并把执行口径传给模型；成果时间仍与项目时间区分。
6. 专项报告需求遗漏显式主题和覆盖重点。补充自然语言采集；重点作为补充检索查询，年份/资料范围不变。
7. 成果及报告正文的引用数字原为普通文本。复用引用渲染与预览处理，支持从正文进入原文。
