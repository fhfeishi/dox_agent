## 中文摘要

机器人视觉伺服控制广泛应用于非结构化工作环境，其控制性能往往受到多种因素影响。现有研究方法主要集中在解决视觉伺服系统中运动学约束、不确定性和干扰抑制、非线性控制优化等问题。然而，针对不确定性环境下的机械臂约束视觉伺服控制，还存在如下主要瓶颈：1）非线性优化导致控制的实时性不高；2）图像测量引起的状态时延；3）高/低层级多速率控制中的性能优化。基于此，本项目主要开展如下研究内容：1）对约束视觉伺服系统非线性运动学进行分析，对不确定性进行量化表征，建立基于逐次线性化的线性时变模型；2）设计时延状态/干扰观测器对未知动态进行重构，建立基于强化学习的变时域模型预测控制策略；3）将所提出的方法进行仿真分析与实验验证，并在变电站运维系统中开展应用研究。本项目的研究将为不确定性环境下的机械臂约束视觉伺服控制提供切实可行的理论和方法，提高机器人控制系统性能，促进视觉伺服技术工程化应用。

## 英文摘要

Visual servoing control is widely used in unstructured working environments, and the control performance is often affected by various factors. Existing research methods mainly focus on solving the problems of kinematic constraints, uncertainties and disturbances rejection, nonlinear control optimization in visual servoing systems. However, for the visual servoing control of robot manipulators in an uncertain environment, there still exist the following main bottlenecks: 1) The real-time performance of the control is not high due to nonlinear optimization; 2) The state is delayed induced by image measurement; 3) Performances need to be optimized in high/low level multi-rate control. To this end, this project mainly carries out the following research contents: 1) The nonlinear kinematics of the constrained visual servoing system is analyzed and the uncertainty is quantitatively characterized, establishing a linear time-varying model based on successive linearization; 2) A delay-based state/disturbance observer is designed to reconstruct the unknown dynamics, and a variable-time-domain model predictive control strategy based on reinforcement learning is developed; 3) Simulation analysis and experimental verification of the proposed method is implemented, and the applications in the substation operation and maintenance system will also be carried out. The research of this project will provide practical theories and methods for visual servoing control of robot manipulators in uncertain environments, improve the performance of robotic control systems, and promote the engineering application of visual servoing technology.

## 结题摘要

随着机器人在电力运维、复杂制造及高风险作业等领域的广泛应用，视觉伺服作为实现机器人精细操作与自主交互的关键技术，正面临不确定环境下性能与安全难以兼顾的挑战。实际应用中，视觉伺服系统普遍存在未知深度、模型不确定、测量时延、多速率采样以及视野与执行器约束等问题，传统方法难以在复杂动态环境中同时保证稳定性、安全性与实时性。针对上述问题，本项目围绕“不确定性环境下机械臂约束视觉伺服”开展系统研究。.项目以视觉—运动耦合建模为基础，系统分析图像特征动态与机械臂运动之间的非线性映射关系，将未知深度、外部扰动和建模误差统一纳入等效不确定项描述框架，构建了适用于预测控制与鲁棒分析的视觉伺服动态模型。在此基础上，针对视觉信息更新频率与底层控制执行频率不一致的问题，提出了多速率变时域鲁棒模型预测控制方法，通过变时域优化与逐次线性化策略降低在线求解复杂度，并将状态/扰动估计结果显式引入预测模型，实现复杂环境下高精度与实时性的统一。同时，面向工程应用中存在的视野约束和动态障碍等安全需求，项目将控制障碍函数等安全机制与模型预测控制相结合，实现了复杂约束条件下的安全视觉伺服与动态避障控制，并进一步探索了强化学习与预测控制相融合的学习增强策略，提升系统在非结构化环境中的自适应能力。.研究成果通过实际机器人系统得到验证。实验结果表明，在动态目标、外部扰动及障碍干扰条件下，所提出方法在轨迹跟踪精度、响应速度和安全性方面均显著优于传统视觉伺服策略。项目执行期间共发表 SCI 论文9篇、EI 期刊论文2篇、EI 会议论文4篇，授权发明专利2项、受理发明专利3项，实现成果转化经费55万元，并支撑企业横向科研合同224.5万元，验证了研究成果的工程可行性与应用价值。项目在不确定性建模、多速率预测控制与安全约束融合等方面形成了系统性方法，为复杂动态环境下视觉伺服控制提供了新的技术路径，并为电力运维等高风险作业场景中的安全自主操作提供了关键技术支撑。
