# Abstract (Brief description of research background, main methods, contributions, and research data):

This research focuses on scientific issues such as the bionic mechanism of insect jump-gliding locomotion, quick transitional control of multi-modal locomotion, and swarm intelligence decision-making in insect-inspired robots. It deeply imitates the local characteristics and overall functions of orthopteran insects like locusts, studying their composite motion characteristics and multi-modal coupling mechanism. The research proposes a bionic configuration mapping and a transitional control method. A hierarchical decision-making control framework for weak-perception swarms is developed. It achieves the complex environmental adaptation of individual miniature robots and the intelligent, efficient collaboration of multi-configuration swarm systems, providing crucial support for the development of intelligent miniature biomimetic robots. First, the multi-modal composite motion characteristics of locusts are analyzed, revealing the optimal timing of wing deployment for their jump-gliding locomotion and clarifying the mechanism for multi-modal motion transitions. A high-energy cable-driven jumping leg and a high-load gliding configuration consisting of a pair of main wings, forewings and a tail are designed. The wing-leg coordinated motion under the actuation of a single motor is successfully realized. Then, by cascading the position and orientation during the transition between crawling, jumping, and gliding modes, an innovative integrated crawling-jumping-gliding multimodal locomotion control method based on reinforcement-learning is proposed. The optimal action strategy of the robot, meeting the highest lift-to-drag ratio, is optimized, improving the robot's switching speed and stability during the transition. A method for etching silicon processes on insulators and constructing multiple stress concentration areas is proposed. A high-precision miniature micro bristle tactile sensor is developed, achieving rapid detection of obstacle contours in unstructured environments. Based on the deblurring networks and map fusion theory, a navigation and localization method for miniature insect-inspired robots is proposed. A weak-perception system for miniature insect-inspired swarm robots is designed. By utilizing intelligent swarm collaboration and obstacle avoidance strategies, the system achieves autonomous deployment, cross-traversal, and map mapping tasks in complex terrains. The first miniature locust-inspired robot at the centimeter scale, capable of crawling, jumping, and gliding with high energy efficiency, has been developed. It has been deployed in a special department for special tasks, enhancing the concealment and safety. The bionic configuration mapping and adaptive modal transition methods proposed in this project have been applied to lunar surface exploration robots and a specialized border patrol inspection robot. These advancements are of significant importance in enhancing security. The research has resulted in the publication of 34 papers in top journals such as IEEE Transactions on Robotics and Mechanism and Machine Theory, and the filing of 20 national and international invention patents, with 7 granted. The research result wins the second prize for technological invention at the 2024 China Association for Automation Awards. It also receives three Best Paper Awards at international conferences such as IEEE ROBI0 2023. The project leader is awarded the 2022 Xiong Youlun Zhihu Outstanding Young Scholar Award.

## 1）蝗虫跳跃-飞翔复合运动建模

蝗虫跳跃主要依靠后胸足进行，其中后胸足由基节、转节、股节、胫节、跗节组成，而股节、胫节是在跳跃中起主要作用的两个重要结构，胫节和股节长度相同，外骨骼相比股节薄，为刚性管状结构。在股节中，存在一个香蕉形、高度硬化、增厚的角质层SLP，由于其具有较高的弹性模量，可以被视作“弹簧”用于蓄能。在跳跃前，SLP被位于股节中的胫骨伸肌牵拉产生弹性形变，实现能量的储存，并且SLP的弯曲程度越大，胫骨的伸展速度越快，因此蝗虫可以通过控制SLP的弯曲程度来控制能量储存的多少进而控制跳跃的高度。此外，股节中还有外骨骼内陷形成的海特勒肿块，其与屈肌腱鞘突构成锁定机构，能够确保跳跃储存的能量不会被提前释放。特别地，不同龄期、独居或群居的蝗虫SLP的刚度会发生改变，这影响了SLP储存的能量，进一步影响了跳跃的表现。屈肌主要是用于拮抗伸肌产生的力保持锁定和触发跳跃。

蝗虫的跳跃分为三个步骤:（i）锁定:胫骨屈肌被激活，当胫骨完全弯曲后被海特勒肿块和屈肌腱鞘突构成的锁定机构锁定（为蓄力做准备）； （ii）共收缩:胫骨伸肌和胫骨屈肌同时收缩，伸肌收缩以牵引SLP拉伸到最大位置储存能量，屈肌收缩以保持锁定，此时胫节和股节之间不发生相对移动；（iii）跳跃:胫骨屈肌及其运动神经元受到抑制，不再产生拮抗力，锁定被解除，胫骨会迅速伸展以产生跳跃。

通过kinovea软件对视频分析得到了蝗虫跳跃时身体与水平夹角的角度、角速度和角加速度。利用角加速度计算得到动量矩与冲量矩，得到的冲量矩小于$5 \times 10^{-3} \mathrm{~g} \mathrm{~mm}^2 / \mathrm{ms}$ ，与自身尺寸相比足够小，不足易引发跳跃失稳，如图1所示，因此可以证明蝗虫在跳跃时不仅在运动学上而且在动力学上有良好的稳定性。

基于上述对蝗虫跳跃运动的分析，为了提高微小型跳跃机器人的跳跃性能与仿生程度，应满足如下特性:（i）与蝗虫的锁定机制类似，有一套受控锁定与释放机构，能够让机器人进行较长时间蓄力并在短时间内将能量释放；（ii）与蝗虫SLP的控制机制类似，提高弹簧的行程的上限足够大，能在保持机器人尺寸小型化的要求下储存足够的能量；（iii）与蝗虫跳跃时的动力学类似，跳跃时惯性矩足够小，以实现稳定的跳跃姿态。

进一步，蝗虫跳跃的目的是积累足够的速度为后续滑翔提供升力。在起飞阶段，身体角度可以被视为攻角，它影响空气动力学中的升力。空速和攻角都会影响升力，因此分析这两个参数的变化很重要。为了进一步了解空速与攻角之间的关系，我们建立了一个仿真模型，该模型描述了跳跃机器人起飞后的运动特性，并通过给定的初始状态分析了机器人在平面内的轨迹。该模型将蝗虫的运动分为跳跃、过渡和滑行三个主要阶段:（i）跳跃阶段被定义为蝗虫从静止开始到离开地面这一过程，跳跃时翅膀保持收缩状态，因而表现出较差的气动性能。该阶段蝗虫通过与地面相互作用进行加速，并在阶段结束时以初始速度 $v _ { 0 }$ 和初始角速度$\omega _ { 0 }$ 离开地面；（ii）过渡阶段被定义为蝗虫离开地面至翅膀张开前这一过程，该阶段翅膀仍保持收缩状态，蝗虫只受重力作用，做抛物运动；（iii）滑翔阶段被定义为翅膀张开至蝗虫落地这一过程，该阶段蝗虫在重力、气动力、气动力矩的共同作用下进行滑翔。

通过仿真验证了蝗虫的跳跃-滑翔运动有效提升了横向运动范围，如图2所示。给定初始速度 $v _ { 0 } = 3 . 2 \: m / s$ ，初始角速度 $\omega_{0}=0\ rad/s$ ，初始位置 ${ \vec { r } } =$ $[ 0 \; 0 \; 0 . 0 3 ] ^ { T } \: m$ 。显然，蝗虫的跃翔运动扩大了横向移动范围，比起单纯的跳跃运动具备更强的移动能力。

## 2）跃翔一体驱动机理、构型映射与优化

前足和中足是蝗虫爬行运动的关键结构，蝗虫可通过前中足节律的摆动实现前进、后退以及转向等运动；跳跃时通过前中足的支撑调整起跳角；着陆时通过前中足的弯曲缓解地面冲击力。从蝗虫的爬行运动中获取灵感，机器人的爬行模块应具备支撑、前进、转向和减震等功能。其中支撑作用为机器人提供了特定的起跳姿态角度，极大程度上决定了机器人的跳跃轨迹，而为了让机器人具备应对不同环境的可调节的跳跃运动，爬行模块应具备起跳姿态角度调整能力；前进和转向是爬行模块赋予机器人的爬行运动能力，为了应对非结构化的复杂环境，其爬行应具备一定的越障能力。减震功能主要应对着陆时的大冲击情况，机器人需要具备柔性自适应结构吸收冲击能量，以保护整体结构不被破坏。

机器人的爬行模块三维模型如图3所示，包含了轮足结构和减震系统。其中轮足结构由凸轮轮足、一级减速齿轮组、直流电机组成，减震系统由翻转底板和皮筋共同组成。轮足以凸轮作为主要外轮廓，通过直流减速电机驱动，当两个电机同向转动时可实现前进、后退运动，同时具备俯仰角度调整能力；电机反向转动时可以实现机器人转向运动，提供横向姿态调整能力。本研究采用一个可翻转的底板和皮筋组合实现爬行模块的减震设计，将爬行模块的底板一端通过回转副与机体前端相连，在另一端利用皮筋作为弹性元件与机架进行柔性连接。可以看出，当机器人着陆时，爬行模块的轮子将受到来自前下侧的冲击，该地面冲击力将对底板产生绕回转副的一个逆时针旋转的力矩，使底板绕回转副产生逆时针旋转，同时该运动将拉伸皮筋，将大部分冲击能量存储至皮筋中，从而降低着陆冲击力而实现减震。

蝗虫跳跃运动主要依靠一对强壮的后足完成。研究发现，蝗虫在跳跃过程中其质心运动呈现线性轨迹，这增强了其跳跃的稳定性。跳跃时，蝗虫通过屈肌将后腿收缩折叠，并通过海特勒肿块实现锁定，通过伸肌不断收缩积蓄能量，最后屈肌舒张释放后足完成高爆发跳跃。凭借“蓄力-锁定-释放”机制，蝗虫能获得远高于肌肉最大负载的作用力，从而能瞬间运动远超自身体长的运动距离。为此，本研究借鉴蝗虫后胸足的骨骼肌肉模型及其工作原理，构建了如图4所示的跳跃模块。该模块由丝杠电机、滑块、挂钩、跳跃连杆、拉簧、跗节等组成。丝杠电机连接线绳1与滑块，当其正向旋转时线绳1会被缠绕到丝杠上，滑块会向前平移；当其反向旋转时线绳1将被释放，滑块向后移动并牵引线绳2驱动挂钩打开。具体工作流程如下:

（i）蓄力:电机正向旋转n圈，长度为l=n×d的线绳缠绕在丝杠上，并带动腿部收缩；（ii）锁定:当等于腿部伸展的行程L时，腿部完全收拢并挂在钩子上，实现能量的锁定；（iii）松线:电机反向旋转来松动缠绕的线绳，而腿部此时仍被挂钩锁住，保持收拢状态；（iv）发射:电机继续反向旋转，滑块移动 $\Delta \mathbf { s }$ 的距离，并通过一根绷紧的线绳触发钩子，腿部瞬间蹬展，完成跳跃。

$$
\max[(x_{E}-x_{I})^{2}+(y_{E}-y_{I})^{2}]_{step=n}

为优化跳跃机构的稳定性，考虑到机器人的绝代部分质量集中于身体质心，因此有牛顿第二定律可知，身体质心上的惯性力和惯性力矩可近似替代外力。因此，我们采用牛顿-欧拉法递推机器人各部分的惯性力及惯性力矩，希望机器人身体部分受到的惯性力方向尽可能一致，受到的惯性力矩在起跳阶段的积累尽可能小，如下:

在详尽的碰撞实验分析框架内，我们观测到了一种显著现象:机翼在遭遇障碍物后的精确0.1秒内即触发弹出机制，此现象无论发生于上冲程或下冲程的任一阶段，均展现出高度的动态响应性。值得注意的是，自适应前缘设计在此情境中发挥了关键作用，它有效地吸收了障碍物对后翼产生的反作用力，从而在不中断或扰乱原有拍打运动模式的前提下，实现了对外部冲击的缓冲与适应。为了进一步阐明这一机制的具体效应，我们深入剖析了一次具有代表性的碰撞实验案例。在此次实验中，碰撞事件直接导致了被碰撞机翼的偏差角度发生显著变化，进而引发冲程幅度的缩减与振动频率的降低。通过精确的数据测量与理论分析，我们明确地指出，这一系列变化对升力产生了不利影响，具体表现为飞行高度的即时损失。然而，除直接受碰撞影响的机翼部分外，其余飞行组件并未遭受到显著负面影响，保持了较高的结构完整性与功能稳定性，验证了系统设计的冗余度与鲁棒性。图8直观地展示了这一飞行过程中的关键阶段以及对比实验。

通过深入且系统地探究了机翼的被动折展机制，通过精心设计的双侧机翼碰撞实验，全面评估了采用被动折展技术的机翼在遭遇障碍物时的动态响应与恢复能力。当此类机翼的前缘遭遇障碍物时，其内置的镍钛合金能够即时触发自适应折叠机制，有效吸收并储存碰撞过程中产生的弹性势能。随后，在机翼顺利穿越障碍物或缝隙后，储存的弹性势能得以迅速释放，驱动前缘恢复至初始形态，从而确保机翼能够无缝衔接至正常的飞行状态，这一过程显著增强了机翼的碰撞耐受性与恢复效率。 2

相较于已有的依赖铰链机制实现碰撞恢复的机翼设计，所提出的仿生被动柔性折展前缘技术展现出了显著的优势。具体而言，该技术能够根据障碍物或缝隙的具体形态与尺寸，自适应地调整弯折点与形变路径，这一特性有效分散了碰撞应力，避免了应力在固定铰链点上的过度集中，从而延长了机翼结构的整体寿命。此外，由于被动折展机翼在结构上更为紧凑且灵活，其转动惯量相对较小，这意味着在相同的动力条件下，该类型机翼能够实现更高的扑动频率，不仅提升了飞行效率，还增强了机动性与响应速度。

蝗虫的飞行结构主要为前-后翅和腹部，后翅宽大提供主要的升力，前翅细长辅助飞行，腹部摆动可以调整飞行姿态。蝗虫的翼翅具备折展功能，能在飞行时展开以获得大的飞行升力，而在跳跃等运动时折叠以减小运动阻力，从而很好地解决了多模态运动之间的运动矛盾。长距离飞行时，蝗虫可以借助低空气流滑翔，从而凭借较低的能耗实现远距离运动。

本研究借鉴蝗虫的气动布局设计了如图9所示的滑翔模块，主要由螺旋桨动力系统、折叠双翼和尾翼组成。螺旋桨动力系统为机器人滑翔提供主动动力，可提升机器人空中运动距离；折叠翼的设计极大缓解了滑翔大升力需求与跳跃小阻力需求的矛盾；机器人配置的气动尾翼通过较大的尾翼面积与气流作用形成翻转力矩，进而控制机器人的俯仰姿态。

## 3）爬行-跳跃-滑翔多模态融合与快速切换控制

本研究借鉴蝗虫的跨域运动方式，提出仿蝗虫机器人灵活爬行、长距离跳跃与稳定滑翔的耦合运动控制策略，如下所示:

（i）爬行运动控制:机器人爬行过程，通过控制轮足电机的旋转，实现机器人在世界坐标系位置的改变。操作者向机器人发送目标位置信息，机器人通过解算器以及轮腿模型进行逆运动学求解。接下来，地面模式选择器生成机器人直行或转向的信号。最后，通过PD运动控制器实现轮足电机的位置控制。

（ii）跳跃运动控制:在爬行运动控制的基础上，机器人跳跃阶段通过控制跳跃足的电机进行蓄力与释放。首先，机器人在轮足可调节的5个离散角度中选择最佳角度，作为机器人起跳角度。接下来，通过控制丝杆电机的正转实现跳跃足结构的蓄力。最后，通过电机反转到指定位置完成跳跃的触发，实现能量的瞬间释放。

（iii）飞行与滑翔控制:利用跳跃阶段的动力学模型可得到跳跃阶段末期的机器人位姿，滑翔运动过程首先通过轨迹规划器获得起跳角度下的最优跃翔轨迹，并将其作为控制器的前馈。接下来，利用强化学习控制器通过控制展翅时机、前置螺旋桨油门开度以及尾翼的偏置，调整机器人空中姿态，生成跳跃-滑翔模态的动作序列，以此实现机器人的位姿调整。最后通过IMU实时监测机器人的姿态，并将其作为控制器的反馈，以此提高控制精度。

![](images/page_17_image_7.jpg)

图14 多模态耦合的运动控制框图

飞行控制方面，本研究提了出一种有尾双层扑翼飞行机器人近悬停点的控制方法。为了提高有尾扑翼飞行机器人的稳定性，对其扰动进行姿态镇定，选择以尾翼的水平偏角作为控制变量设计状态反馈控制器。该反馈控制器不仅能较快地对悬停状态受到的扰动进行抑制，而且响应过程振荡较少，系统的平稳性较好。

在纵向姿态稳定的基础上，可通过单控制信号实现对双层扑翼飞行机器人在悬停点附近的飞行控制。

有尾双层扑翼飞行机器人如图15所示。机器人由上下两对翅膀组成，呈X型布局，由一个电机带动两套曲柄摇杆机构产生扑动，机身后部具有一个水平尾翼，在电磁舵的控制下可以产生水平偏转角度。我们分别在建立如下的惯性坐标系 $X _ { \mathsf { e } } Y _ { \mathsf { e } } Z _ { \mathsf { e } }$ 和机体坐标系 $X _ { b } Y _ { b } Z _ { b }$ ，坐标系原点位于飞行器重心处。在机器人不产生横侧向运动的条件下，飞行器只产生沿着 $\mathsf { X _ { b } }$ 的切向力 $\mathsf { T } \mathsf { b }$ 和沿着 $\mathrm { Z b }$ 的法向力$N b$

![](images/page_18_image_4.jpg)

图15 有尾双层扑翼飞行机器人机构示意图

利用牛顿欧拉运动方程，在机体坐标系 $X _ { b } Y _ { b } Z _ { b }$ 中建立飞行动力学方程。针对双层扑翼微型机器人尾翼气动力模型进行线性化展开，并转化为状态空间形式:

$$
\begin{array} { r } { \left[ \begin{matrix} { \delta \dot { u } } \\ { \delta \dot { w } } \\ { \delta \dot { q } } \\ { \delta \dot { \theta } } \end{matrix} \right] = A \left[ \begin{matrix} { \delta u } \\ { \delta w } \\ { \delta q } \\ { \delta \theta } \end{matrix} \right] + B \cdot \beta , } \end{array}
$$

其中， $\mathsf { A }$ 是系统矩阵，B是控制矩阵。具体表达式如下方所示:

$$
A = \left[ \begin{matrix} { \frac { C _ { T u } } { m ^ { + } } } & { \frac { C _ { T w } } { m ^ { + } } } & { \frac { C _ { T q } } { m ^ { + } } } & { - \quad g ^ { + } } \\ { \frac { C _ { N u } } { m ^ { + } } } & { \frac { C _ { N w } } { m ^ { + } } } & { \frac { C _ { N q } } { m ^ { + } } } & { 0 } \\ { \frac { C _ { M u } } { I _ { y } ^ { + } } } & { \frac { C _ { M w } } { I _ { y } ^ { + } } } & { \frac { C _ { M q } } { I _ { y } ^ { + } } } & { 0 } \\ { 0 } & { 0 } & { 1 } & { 0 } \\ \end{matrix} \right] , \quad B = \left[ \begin{matrix} { \frac { C _ { T \beta } } { m ^ { + } } } \\ { \frac { C _ { N \beta } } { m ^ { + } } } \\ { \frac { C _ { M \beta } } { I _ { y } ^ { + } } } \\ { 0 } \\ \end{matrix} \right]
$$

至此，得到了有尾双层扑翼飞行机器人纵向运动方程在平衡点附近的的小扰动线性化方程。

由于扑翼飞行器在纵向不稳定，悬停时受到扰动很快就进入振荡发散状态，因此需要实时反馈控制以实现对扰动的镇定。在昆虫的纵向运动研究中，有一种典型的控制思路，将昆虫的纵向运动当作多输入多输出系统进行处理，这种控制方法需要较多的控制自由度，而其复杂的运动机构却也限制了扑翼飞行机器人的进一步微型化。因此，本文提出只利用尾翼水平偏转角对纵向状态扰动进行镇定，这是典型的单输入系统的状态反馈控制问题。首先进行系统的可控性分析。系统可控性矩阵为:

$$
\mathbf { \mathit { S } } = \left[ \begin{matrix} { \mathbf { \mathit { B } } } & { \mathbf { \mathit { A B } } } & { \mathbf { \mathit { A } } ^ { 2 } \mathbf { \mathit { B } } } & { \mathbf { \mathit { A } } ^ { 3 } \mathbf { \mathit { B } } } \\ \end{matrix} \right]
$$

该矩阵阶数为4，为满足系统可控性条件，对该扑翼飞行机器人进行状态反馈，控制系统示意图如下方所示。设状态反馈增益矩阵为: 2

$$
K = ( k _ { u } , k _ { w } , k _ { q } , k _ { \theta } )
$$
