## 中文摘要

本课题针对动态环境下的智能体决策模型、实现方法和群智算法展开研究。首先，在分析智能体模型问题基础上，构建智能体状态-决策映射模型。具体地，针对静态和动态环境，分别建立静态和动态映射模型，研究模型状态端到决策端的映射关系，并设计状态序列与决策集的表示方法。其次，为了具体实现智能体状态到决策的映射，基于静态映射模型，设计静态环境下智能体行为决策的神经网络及训练方法。为了适应动态环境，在静态环境下的决策网络及训练方法基础上，利用动态映射模型设计动态环境下智能体行为决策的神经网络及训练方法，使智能体能面对不同环境做出适应其状态的行为决策。进一步地，面向智能体模型衍生的典型群智算法，设计一系列基于神经网络行为决策的群智算法，并将其应用于求解不确定性调度模型中的关键因素特征选择、参数优化和工序优化问题。本课题的开展为解决动态环境下的复杂优化问题提供有效方法和理论指导，具有重要的学术意义和应用价值。

## 英文摘要

This project focuses on agent decision-making models, implementation approaches and swarm intelligence algorithms under dynamic environment. Firstly, the agent state and decision mapping models are designed on basis of the analysis for issues of agent model. Specifically, the static and dynamic mapping models are constructed respectively for static and dynamic environments. The mapping relations between the state layer and the decision layer are investigated, and the state sequence & decision set are represented in detail. Subsequently, to realize the mapping between the state and the decision practically, based on the static mapping model, a neural network and its training method for agent behavior decision are designed for static environment. To adapt to the dynamic environment, on basis of such a static decision-making network and its training method, we use the dynamic mapping model to design a new kind of neural network and training method for agent behavior decision under dynamic environment. So that, the agent can make the appropriate behavior decision to match its state in different environments. Finally, facing to the typical swarm intelligence algorithms derived from agent model, we propose a series of swarm intelligence algorithms based on neural network behavior decision, which are further utilized to solve feature selection of key factors, parameter optimization and process optimization in uncertain scheduling model. This project will provide effective approaches and theoretical guidelines for solving complex optimization problems in dynamic environment, delivering important academic significance and application value.

## 结题摘要

在动态优化方面，本项目设计进化指导神经网络辅助的动态优化算法和搜索引导网络辅助的动态粒子群优化算法。进化指导神经网络辅助的动态优化算法收集优秀的粒子对，并将它们用于训练神经网络，同时为每个输入粒子提供更有前景的位置作为学习目标。在粒子进化阶段，种群中的粒子将以一定的比例通过神经网络辅助的方式进化，而另一部分粒子则采用原始的粒子群进化；搜索引导网络辅助的动态粒子群优化算法中的每个隐藏节点由代表群体中个体的候选学习目标的中心和具有固定值的宽度组成。通过一些彼此距离尽可能远离的粒子最佳位置和随机生成的粒子来设置网络的隐藏节点中心。每个粒子从网络的隐藏节点中心选择其局部和全局学习目标。此外，利用强化学习来获取网络的期望输出。根据期望的输出来调整隐藏节点并有效地更新权重。在动态多目标优化方面，本项目设计粒子搜索指导网络和多区域趋势预测策略。粒子搜索指导网络以学习的方式在搜索过程中指导粒子的搜索动作。通过引入强化学习，以奖励或惩罚的方式获得期望输出，从而学习在每个环境中应该做出的动作。多区域趋势预测策略首先在目标空间所划分的多个子空间内计算并预测帕累托解集的趋势，充分提取历史环境帕累托前沿信息，提高预测策略的性能。其次，基于上一环境的帕累托解集，多区域趋势预测策略生成多样性的个体并引入初始种群。基于预测的帕累托前沿趋势，多区域趋势预测策略将种群引导至新环境中有希望快速收敛的区域。通过本项目的开展，在本领域国内外重要期刊及会议上发表高质量论文18篇，其中发表/录用SCI(E)检索论文13篇，发表会议论文5篇，申请发明专利5项，授权发明专利4项。另外，还开发了一系列通用的优化软件，以及针对动态环境柔性调度的专用优化软件，向学术界共享。并撰写课题的研究报告，培养博士研究生两人、硕士研究生9人，圆满完成本项目制定的预期成果。
