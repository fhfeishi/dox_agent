## 中文摘要

无人驾驶船舶是改变未来航运模式的重要载体。本项目以突破无人驾驶船舶走向应用的技术瓶颈为目标，对无人驾驶船舶自主航行决策与控制进行基础科学研究。首先，借鉴人脑瞬时记忆、短时记忆和长时记忆机制，优化设计深度强化学习算法架构，构建融合人脑记忆模型的深度强化学习经验记忆库，通过改进记忆机制实现对数据的深层记忆和遗忘，进而获得人脑记忆机制启发的无人驾驶船舶自主航行决策方法，阐明无人驾驶船舶自主航行决策机理；其次，以动态面控制策略为基础，结合不确定性和扰动估计器、事件触发机制，建立基于事件触发的动态面控制律，考虑执行器输入饱和约束，设计辅助动态系统，综合故障检测器与故障模型，获得基于事件触发的容错控制策略；最后，构建人脑记忆机制启发的无人驾驶船舶自主航行决策与控制方法。对所提航行决策与控制方法有效性进行实验验证，从理论和实践两方面推进无人驾驶船舶自主航行技术发展，为无人驾驶船舶提供核心理论和技术支撑。

## 英文摘要

Unmanned ship is an important carrier that will change the future shipping mode. This project aims to break through the technical bottleneck of the application of unmanned ships and basic scientific research on autonomous navigation decision-making and control of unmanned ships are conducted. Firstly, inspired from the human brain's ultra-short-term memory, short-term memory and long-term memory mechanism, the architecture of deep reinforcement learning algorithm is optimized in which the human brain memory model is integrated in the experience memory library. By improving the memory mechanism, the deep memory and forgetting of data are realized, and then the decision-making method of autonomous navigation of unmanned ships inspired by the human brain memory mechanism is obtained. Secondly, the dynamic surface control law based on event triggering is established combined with uncertainty and disturbance estimator and event triggering mechanism. Considering the actuator input saturation constraint, the auxiliary dynamic system is designed, and the fault detector and model are integrated to obtain the fault-tolerant control strategy based on event triggering. Finally, the autonomous navigation decision-making inspired by human brain memory mechanism and control strategy of unmanned ship are completed. The effectiveness of the proposed navigation decision-making and control method is verified by simulation and real experiments, which promotes the development of autonomous navigation technology of unmanned ships from both theoretical and practical aspects, and provides core theoretical and technical support for unmanned ships.

## 结题摘要

本项目面向无人驾驶船舶在复杂海洋环境下的自主航行决策与控制需求，重点解决长期任务中易出现的通信受限、感知受限及执行器故障等关键问题，开展了融合人脑记忆模型的无人艇自主航行决策与容错控制研究。在航行决策方面，项目突破了传统避碰算法的局限，基于深度强化学习构建了不同场景下的安全航行决策模型。针对感知不完全场景，引入了记忆机制与门控循环单元，通过历史信息补偿实现了短期记忆驱动的智能避碰；结合《国际海上避碰规则》与人工势场的改进深度Q学习算法，提升避碰决策安全性与合规性；利用相对速度障碍与近端策略优化构建复合奖励机制，显著提高了多船交互避碰的成功率。在运动控制方面，项目提出了系列算法：为应对通信受限，构建了基于视线法、非线性递归滑模控制与动态事件触发机制的路径跟踪算法；为解决多约束与执行器饱和，设计了固定时间扩展状态观测器与饱和动态滤波控制律；为抵御外界干扰与网络攻击，提出了抗扰事件触发非线性模型预测控制与预测补偿机制，使其能在拒绝服务攻击下保持性能稳定；对于多艇编队与船舶列车控制，则融合干扰估计、自适应增益调节与图论拓扑，实现复杂环境下安全鲁棒协同控制。实船验证表明，该系列算法在真实海洋环境中具有良好的可行性与有效性。项目成果在Ocean Engineering、ISA Transactions、Applied Ocean Research、Applied Mathematics and Computation等国际高水平期刊发表SCI论文16篇，申请国内发明专利20项、授权10项；人才培养方面，累计培养毕业研究生10名，其中博士生1名、硕士生9名；项目成果获得福建省科技进步一等奖1项、福建省首批人工智能典型应用场景1项、全国船舶与海洋工程学科高等教育教学成果二等奖1项、中国航海学会技术发明二等奖1项。
