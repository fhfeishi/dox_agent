## 中文摘要

学习跨视角相关性特征能有效发挥双视角钼靶图像的诊断作用，对提高乳腺癌诊断精度至关重要。但双视角钼靶图像在空间上难对齐、在时间上不同步且样本量少，使跨视角相关性特征学习困难。为此，本项目通过三大研究内容对跨视角相关性特征学习这一关键技术瓶颈进行突破：1）针对空间非对齐性，研究基于混合注意力机制的特征对齐方法，以特征对齐代替空间对齐，有效学习空域跨视角相关性特征；2）针对时间非同步性，研究基于常微分方程的特征积分方法，实现稠密时序特征编码，深度优化时域跨视角特征相关性；3）研究双视角图像合成方法，基于生成对抗学习迁移病灶，实现数据增广，缓解小样本下相关性特征学习过拟合问题。本项目将提供非对齐空域上、非同步时域上、小样本下跨视角相关性特征学习的关键技术，并基于此研发一套新型双视角乳腺癌计算机辅助诊断系统，提高乳腺癌良恶性分级和转移风险评估两大临床任务的诊断精度，具有重要的科学意义和应用价值。

## 英文摘要

Learning the cross-view correlation feature can give full play to the diagnostic effect of the dual-view mammogram, which is crucial for improving the diagnostic performance of breast cancer. However, the dual-view images are spatially misaligned, temporally irregular-sampled, and with a small amount, which hinders the cross-view correlation feature learning significantly. This project aims at breaking through this key technical bottleneck by three research contents: 1) studying on hybrid attention based feature alignment method, aligning features instead of images to effectively learn the spatial cross-view correlation features; 2) studying on ordinary differential equation based feature integration method, constructing dense temporal features to effectively learn the temporal cross-view correlation features; 3) studying on dual-view image synthesis method, augmenting data by lesion transferring based on generative adversarial learning to alleviate the overfitting problem in cross-view correlation feature learning. This project will provide the key technique of learning the cross-view correlation features for spatially misaligned, temporally asynchronous and small datasets. Based on the technique, a new type of dual-view computer-aided diagnosis system of breast cancer can be developed, which can improve the performance of breast cancer classification and metastasis assessment, and thus is of great scientific significance and application value.

## 结题摘要

本项目围绕乳腺钼靶计算机辅助诊断（CAD）系统中的关键挑战，在小样本学习、良恶性分类及转移风险评估等方面取得了系统性创新成果。针对数据稀缺、视角非对齐和时序建模困难等难题，项目提出了多项原创性技术方法：基于门控条件扩散模型（GCDM）实现了单视角乳腺图像的可控合成，FID指标降至26.77，Mass IoU提升至86.30%；开发了融合条带注意力与隐式三维建模的跨视角转换方法（CA3D-Diff），在CC到MLO转换中PSNR达20.537，较基线提升超过11%；设计了双视角关联特征挖掘网络（DCHA-Net），在INbreast数据集上分类准确率达到95.5%，AUC值为0.950；构建了时序-空间分解式Transformer模型，有效利用多时间点信息提升了转移风险评估精度，较单时间点模型提升7.6%。研究成果显著，共发表高水平学术论文8篇，均以本项目为第一资助。其中包括IEEE Transactions on Medical Imaging等中科院1区期刊论文3篇，以及NeurIPS、ACM Multimedia、IJCAI、MICCAI等顶级会议论文5篇。在人才培养方面，项目负责人依托本项目支持，获得国家自然科学基金面上项目资助和武汉市优秀青年人才称号；项目支撑的4名硕士研究生中，2人荣获国家奖学金。本项目为医学影像分析提供了可控生成、跨视角建模与时序预测的新范式。所发展的技术体系为构建高性能、高鲁棒性的乳腺癌CAD系统奠定了坚实基础，对推动辅助诊断工具的临床转化具有明确价值。通过方法创新与系统集成，本项目显著提升了乳腺钼靶影像分析的准确性与实用性，为乳腺癌早期筛查和精准诊断提供了有效的技术支撑。
