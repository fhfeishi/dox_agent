## 中文摘要

基于视觉的自主导航是机器人和计算机视觉领域的重要课题之一，尽管经历了数十年的研究，现有的算法在鲁棒性、泛化能力和适应性方面，仍然不及生物体所具备的导航策略。视觉导航与认知模型方法的结合，将使机器人逐步具备类似于生物体的以视觉信号为主的导航能力，有着重要理论意义与应用价值。但目前认知导航模型在接近真实的场景下，容易受到环境中动态因素的影响，算法的稳定性和可靠性差。因此，本课题开展动态环境下的认知导航模型研究，包括以下四个方面：1）动态环境下的模型鲁棒性研究，提高模型抗环境因素干扰的能力。2）动态环境下的记忆结构研究，提高模型适应环境变化的能力。3）使用多任务模型方法提高导航任务的性能，结合传统导航方法来提高动态环境中导航的稳定性和实用性。4）建立视觉导航验证系统，进行算法性能评估。课题研究的相关成果，有助于推动真实场景下认知导航的理论与应用创新。

## 英文摘要

Visual navigation is one of the important topics in the field of robotics and computer vision. Although navigation has been studied for decades, existing algorithms are still inferior to biological navigation capabilities in terms of robustness, generalization, and adaptability. The combination of visual navigation and cognitive models will enable robots to gradually have visual navigation capabilities similar to organisms, which has important theoretical and application value. However, in real environment, the stability and reliability of cognitive navigation model became weak, when the model is affected by dynamic factors of the environment. Therefore, this project studies cognitive navigation model in dynamic environment, including the following four aspects: 1) Investigate model robustness in a dynamic environment to improve the model's ability to resist environmental interference. 2) Study memory structure in a dynamic environment to improve the ability of the model to adapt to environmental changes. 3) Propose multi-task model method to improve the performance of navigation tasks, and mixed model which is combined with traditional navigation methods to improve the stability of navigation in dynamic environments. 4) Establish a visual navigation verification system to perform algorithm evaluation. The research results of the project will promote the theoretical and application innovation of cognitive navigation in real world.

## 结题摘要

本项目的主要目标是充分利用智能体在过去积累的经验信息，提高其在动态变化环境中的探索能力，从而提高强化学习在视觉导航中的学习效率和模型性能。具体来说，本项目的研究内容包含如下几个方面：首先，提出了高效回合记忆机制，缓解学习中对经验数据的过拟合问题，提高智能体在程序生成环境中的探索效率。其次，提出含有专家数据的经验回放方法，解决智能体在训练起始阶段学习效率低并且模仿学习容易产生对专家数据过拟合的问题，提高智能体在训练起始阶段的学习效率和收敛阶段的性能。而后，提出自模仿引导的策略梯度方法，避免了视觉语言模型特征生成的内部奖励性能下降问题，提高了视觉语言模型特征在强化学习任务中的性能表现。最后，设计自适应探索调节机制，缓解了学习过程中探索和利用的平衡问题，提高了智能体在稀疏奖励环境下的学习效率和性能表现。上述方法的成功实施，不仅有助于推动强化学习技术的发展，也为解决现实世界中的复杂和动态问题提供了有价值的解决方案。
