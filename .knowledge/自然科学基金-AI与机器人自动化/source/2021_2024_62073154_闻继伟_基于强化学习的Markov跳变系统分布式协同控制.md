## 中文摘要

长期以来，Markov跳变系统（MJS）控制理论根植于随机Lyapunov函数方法，其灵活性和有效性一直是热点研究问题。然而在应对网络化的实际工程问题时，现有的MJS理论却面临着系统和网络环境中的诸多未知因素，比如系统参数跳变、通信拓扑跃迁的转移概率未知等，给分布式协同控制（CDC）带来的巨大挑战。本项目针对这一问题开展如下研究工作：通过时序差分法习得未知参数值函数的概率收敛值，基于边学边控的思想和几何拓扑学，建立MJS的CDC设计一般框架；出于节能考虑，构造阈值随系统动态过程变化的自触发方案和事件驱动机制，用Q-学习法习得最佳触发策略；用回报函数法构造非单调Lyapunov函数，降低上述设计策略的工程保守性，并实现CDC异步设计；将部分理论成果应用到微电网系统，改善控制性能。项目旨在揭示强化学习算法与CDC设计的内在联系并拓展其适用范围，为复杂大规模控制问题的求解及应用提供有效解决方案。

## 英文摘要

For a long time, the control theory of Markov jump systems (MJSs) is established based on stochastic Lyapunov function approach. Its flexibility and effectiveness are fully discussed in recent years. However, the existing theory still faces challenges when dealing with practical problems under the networked environment, such as collaborative distributed control (CDC) for systems when there exist many unknown situations. For example, the transition probabilities of the system jumping parameters or the switching communication topology is usually unknown due to the practical complexity and difficulties. The research work focuses on the following four aspects. First, by means of temporal difference approach, the probabilistic characterization of the value function for unknown parameters can be obtained. Then, based on the idea of learning while controlling and geometric topology, we can build a CDC design framework for MJSs. Second, considering energy savings, the self-triggering scheme and event-driven mechanism, in which the threshold changes with dynamics of the system, are constructed by using an adaptive technique. Triggering schemes can further be optimized by Q-learning approach. Third, in order to reduce engineering conservatism of the above design strategies, the reward function method is employed to construct a non-monotonic Lyapunov function. It can further be used to design CDC controller in the case of asynchronous jumping. Finally, some theoretical results will be applied to the micro-grid system in order to improve the control performance. The purpose of this project is to reveal the intrinsic relationship between reinforcement learning algorithm and CDC design, and expand its applications. It is expected to provide effective solutions for solving complex large-scale control problems.

## 结题摘要

本项目围绕Markov跳变系统（MJSs）的理论及其应用研究展开，重点研究了MJSs及其广义形式（GMJSs）在不确定环境下的分析、学习与控制问题。从研究背景来看，MJSs因其随机性、不连续性和复杂动态特性，已成为系统与控制科学中的关键领域，且在通信、光伏能控系统和微电网等领域具有广泛的实际应用价值。本项目的研究方向聚焦于跳变参数未知（包括动力学和转移概率）、网络环境下的拓扑跃迁、强化学习中的数据稀缺性及工程实现中的挑战，突破了MJSs在分布式控制框架下的理论与应用瓶颈。.项目的主要研究内容涵盖了MJSs和GMJSs在跳变参数未知和拓扑跃迁转移概率未知下的最优控制问题，结合强化学习方法，如时序差分法、Q学习，Actor-Critic学习网络，提出了基于分布式架构的控制与一致性设计。同时，针对网络环境下的能控性和学习效率，引入自触发机制，研究GMJSs在随机环境中的通信能耗与回报最优化问题。项目通过引入无约束控制/滤波网络与强化学习算法，实现了MJSs 和GMJSs的自适应估计与实时控制。.项目的重要结果包括：(1) 半Markov切换通信拓扑下GMJSs的分布式滤波；(2) 异步传输网络下GMJS的自触发一致性滤波；(3) 基于时序差分学习的半MJSs H∞控制；(4) 基于非零和博弈的MJSs自适应最优跟踪策略；(5) 基于博弈Q学习的非线性GMJSs约束预测控制。.在关键数据方面，我们通过基于工程实例的计算机仿真，验证了MJSs和GMJSs在动力学参数未知和不同不确定环境下的稳定性与鲁棒性，得到了显著的性能提升数据。强化学习算法的迭代训练结果表明，其学习效率与控制效果优于现有方法。.本项目的科学意义在于推动了MJSs理论及其工程应用的进一步发展，特别是在强化学习与分布式控制框架下，为不确定环境中的复杂系统提供了新的学习与控制思路，为解决MJSs的工程应用难题提供了理论支撑与技术路径，具有重要的学术与实际价值。
