## 验收中发现并修复的问题

1. 审查模型与公开题录检索忽略系统代理（`trust_env=False`），在需代理网络下全部连接重置。
2. 模型在一个 `source_id` 中写入多个编号，导致 11/12 条专业意见被判为引用无法定位；改为接受多个编号、以首个有效编号定位，其余作为“另见”。
3. 单次返回非法 JSON 即中止整个审查；网络异常和非法 JSON 现重试一次。
4. 指南输出超长被截断即失败；现将该批原文对半拆分重试。
5. 长 PDF 的分块理解输出超限即中止审查；现将截断的块对半拆分重试。
6. PDF 中“2022.1 – 2022.12”“2003.9-2007.12，…”等日期行被识别为标题，导致章节截断；编号标题现限定为 1–2 位章节号。
