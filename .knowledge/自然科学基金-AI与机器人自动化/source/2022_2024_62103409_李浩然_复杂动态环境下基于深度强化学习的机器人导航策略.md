## 中文摘要

智能移动机器人的通行能力是提高其服务效率的关键。经典导航方法在解决复杂动态环境下机器人导航问题时面临巨大的局限性，因此，深度强化学习算法成为解决该问题的突破点之一。本课题针对深度强化学习算法在解决实际复杂动态环境下的机器人导航问题时亟需解决的关键科学问题，展开以下研究：1、针对仿真环境与真实环境之间的差异性问题，从机器人本体响应的差异和周围环境构成的场景分布差异两个角度出发，研究机器人动力学响应补偿方法和场景生成方法；2、针对动态环境中移动物体的交互不确定性，研究交互不确定下的深度强化学习导航算法；3、针对边缘场景在算法迁移过程中产生的不确定性问题，研究基于鲁棒对抗强化学习的边缘场景生成和鲁棒策略学习方法。最后将所研究的方法部署到实际的环境中，构建实际和仿真结合的深度强化学习算法训练闭环，为深度强化学习解决实际复杂动态环境下的机器人导航问题奠定扎实的方法和理论基础。

## 英文摘要

The navigation of intelligent mobile robots is the key to improve their service efficiency. Classical navigation methods face great limitations in solving the problem of robot navigation in a complex dynamic environment. Therefore, the deep reinforcement learning algorithm has become one of the breakthrough points to solve the problem. This project focuses on the key scientific problems that need to be solved when the deep reinforcement learning algorithm is used to solve the robot navigation problem in the actual complex dynamic environment. The following research is carried out: 1. Aiming at the difference between the simulation environment and the real environment, the dynamic response compensation method and scenarios generation method are studied from two aspects: the difference of the robot body response and the difference of the scenarios distribution of the surrounding environment. Secondly, for the interaction uncertainty of moving objects in the dynamic environment, the deep reinforcement learning navigation algorithm is studied. Thirdly, for the uncertainty problem of edge scenarios during transferring algorithm, the edge scenarios generation and robust policy learning method based on robust adversarial reinforcement learning are studied. Finally, the methods is deployed to the actual environment, and the deep reinforcement learning algorithm training closed-loop is constructed by combining the actual and simulation, which products the theoretical foundation for deep reinforcement learning to solve the problem of robot navigation in the actual complex dynamic environment.

## 结题摘要

本项目围绕复杂动态环境下的机器人导航问题，从仿真环境到实际环境迁移算法、新型深度强化学习方法和虚实结合的深度强化学习训练闭环三个方面开展研究。首先，针对仿真环境和实际环境中机器人动力学习差异和生成场景的差异性问题，开展了面向移动机器人仿真到实体迁移的虚实融合平台研究，构建了面向不同机器人导航任务需求的仿真环境套件NeuronsGym和NeuronsMAE。针对机器人导航任务中所面临的行为不确定性造成的算法学习困难等问题，研究了基于扩散模型的新型深度强化学习方法，从离线强化学习和在线强化学习两个角度构建了新型、高效的深度强化学习方法。最后，在所构建的平台和方法的基础上，在2022 IEEE CoG国际会议上举办了面向移动机器人仿真到实体迁移的挑战赛，吸引了来自全球40多支队伍报名参赛。依托该项目，发表论文9篇，培养研究生4名，申请专利2项。
