# 四维信息阅读框架（场景 / 问题 / 技术 / 成果）

四维是材料的四个切面，各维可以零项或多项，关系可以不明确；不是四层目录或必须填满的四格。

- 场景：应用环境、对象与业务环节，以及运行条件、干扰和适用边界。
- 问题：机理或系统瓶颈，以及数据、感知、算法和决策难点。
- 技术：架构、理论模型、算法、协议与软硬件策略；保留方法的应用约束，同名不代表同一方案。
- 成果：平台、样机、软件、应用验证、论文与专利；明确区分已取得、预期与原文未明确。

关键事实和原始指标使用原文 [n] 引用，保留数值、单位、基线、样本量和测试条件。不同条件的指标不能直接排名，不用“显著提升”替换实际数据。
仅在所读原文未提供时说明“本次所读资料未提供”，未完整阅读不能断言整份原文未提及。共同出现不代表因果或解决关系。模型归纳、推断与文献事实分开，证据不足明确写出缺口。
按可靠项目身份去重；身份缺失时只报告文档样本数。项目起止年份不代表成果发生时间，无可信时间序列时只做样本差异分析。
框架帮助理解证据，具体输出服从任务要求；报告章节仅由所选模板决定，已发布自定义模板不自动增加章节。
