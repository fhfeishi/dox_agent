## 增量发现

### 1. 中：stage_report 命令入口不具备严格只读保证

- 位置：`datapipe/scripts/stage_report.py:47`；`src/knowledge.py:100`、`:107`、`:110`、`:125`。
- 事实：新脚本先构造普通 `Knowledge`，再调用 stage_view。构造器使用可写连接，执行建表、建索引，缺 `observed_sha256` / `last_error` 时执行 ALTER。脚本只判断 SQLite 文件存在，未排除旧 schema 或空的 SQLite 文件。
- 触发与影响：对已有但未升级的库运行号称只读的诊断命令，会升级或补建表；只读挂载时可能直接失败。现代且完整的库不一定产生实际写入，不能把该条件风险说成所有执行必定写库。没有因 DenseIndex 构造而推断下载或向量重建，其重活是惰性的。
- 测试缺口：`tests/test_stages.py:105` 和 pending 参数化用例是在 `Knowledge` 构造及 publish 之后取快照，只证明函数阶段不改文件，覆盖不到 CLI 构造。测试检索未见 stage_report 入口用例。
- 最小建议：只读诊断入口不得借可写构造器初始化数据库；显式报告旧 schema/未初始化状态，勿在读取时自动迁移。实施时将旧 schema 的 CLI 输入与字节不变断言并入相关入口验证；本轮不实现、不扩测。

### 2. 中：extract 的 missing 混入“原件已变/已丢失，但记录仍存在”

- 位置：`src/stages.py:103`、`:116`、`:134`；`src/knowledge.py:244`；`src/targets.py:91`。
- 事实：stage_view 从 `knowledge.current()` 建 doc 映射，再把 `current.get(doc_id)` 传给 `_extract_state`。原件变化或丢失会退出 current；传入 None 后直接返回 missing，根本不读取 target 文件。与此同时 published docs 仍可由 all/get 读取。
- 静态反例：先有已发布文档和合规 target，随后只改变/移走 source，不执行删除闭合。source 得 changed/missing，search 得 superseded，但 extract 无条件变 missing，即使 target 仍存在、甚至已有损坏标记也不会检查。此结论由分支直接推出，未运行夹具。
- 影响：阶段视图无法区分提取记录真的不存在、记录失效和记录损坏，可能误导补跑；不影响 current 的资格过滤，本轮没有要求让旧资料重新可检索。
- 测试缺口：现有 changed/missing 用例不先写 target，也不断言 extract；独立阶段用例未覆盖该交叉状态。
- 最小建议：保留“新任务是否可用”与“提取产物是否存在”的独立事实。复用 published 元数据读取 target，并明确 source 不 current 时归 stale 还是另附原因；该语义由专题负责人确认，不默默更改状态词或 current 规则。

### 3. 中：年度投入额外按字号缩放，大屏下重新偏离共享图高

- 要求：query「2026-1103 1630」要求三类交互图大小接近、切换没有明显大小跳变，不是数学上强求完全相等。
- 位置：`frontend/src/components/atlas/YearBand.tsx:99`；`frontend/src/components/atlas/LineageRoads.tsx:322`；`frontend/src/styles/globals.css:44`、`:51`、`:602`、`:606`。
- 事实：YearBand 取共享 CSS 高度后又乘 `viewport.font / 14`，LineageRoads 直接使用共享高度。2200 CSS px 宽以上字号 15，3000 以上字号 17。
- 静态计算（非截图）：不启用 baseline，在 2560×1440 CSS viewport 下共享高度为 800，年度图计算为 round(800×15/14)=857；3840×2160 下为 round(800×17/14)=971，而谱系仍为 800。差距 57/171px，不能沿用 1920 下相差 15px 内的验收说明。baseline 的额外空间是显式设计，本轮不据此另报问题。
- 既有证据缺口：query 记录的这次验收为 1920×1080、1440×900，均未触发字号断点。物理 4K 经系统缩放后可能不足 3000 CSS px，不能泛称所有 4K 用户必现。
- 最小建议：由统一图框负责外部绘图区高度，字号缩放留给内部标记/留白；实施时在既有浏览器路径加一个超过 3000 CSS px 的非对比状态检查即可，不另建测试矩阵。本轮按用户要求不运行浏览器，视觉影响仍待实测。
