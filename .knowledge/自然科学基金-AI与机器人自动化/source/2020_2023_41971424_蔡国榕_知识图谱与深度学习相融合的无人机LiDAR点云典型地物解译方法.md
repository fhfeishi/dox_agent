## 中文摘要

无人机LiDAR系统获取的高分辨率三维点云，在测量与制图、大规模城市场景重建等领域具有越来越明显的优势。目前，点云深度学习与地物先验知识相结合的方法，已开始成为无人机LiDAR点云解译领域新的研究热点。其关键问题在于地物知识如何抽取、量化、推理，以及先验知识如何同点云深度学习相互耦合。为此，本项目拟重点研究多维度关联的地物知识图谱构建方法、融合知识图谱和深度学习的多尺度地物候选目标检测方法，基于可变图卷积的地物单体化语义分割方法，以及基于条件生成式对抗网络的地物轮廓提取方法。在地物先验知识的驱动下，探索点云深度学习的语义可解释性，形成稳定、可靠的高分辨率无人机LiDAR点云典型地物解译理论与方法，从而大幅减少点云解译过程中的人机交互。本课题的研究成果有望为地图制图的智能化提供新的理论支撑，预期在基础测绘、智慧城市等领域将具有广泛的应用前景。

## 英文摘要

The high-resolution 3d point cloud obtained by UAV LiDAR systems have more and more obvious advantages in surveying and mapping, large-scale urban scene reconstruction and other fields. Currently, it has gradually become a new research hotspot to introduce ground object prior knowledge into the deep learning framework of UAV LiDAR point cloud. The key problem is how to extract, quantify and reason the ground object knowledge, and how to couple the ground object knowledge with point cloud-based deep learning architecture. To this end, this project will focus on the construction and the information transmission mechanism of ground object knowledge graph, multi-scale ground object detection method integrating knowledge graph and deep learning, the instance segmentation algorithm based on deformable graph convolution, and the ground object contour extraction based on conditional GAN. The purpose is to explore the semantic interpretability of point cloud deep learning,  under the guidance of prior knowledge. Then a stable and reliable theory of high-resolution UAV LiDAR point cloud interpretation for typical ground objects is developed, thus greatly reducing human-computer interaction in the process of point cloud interpretation. This project expected to provide new theoretical support for intelligent map making. The results may have broad application prospects in basic surveying and mapping, smart city and other fields.

## 结题摘要

无人机LiDAR系统获取的高分辨率三维点云，在测量与制图、大规模城市场景重建等领域具有越来越明显的优势。目前，点云深度学习与地物先验知识相结合的方法，已开始成为无人机LiDAR点云解译领域新的研究热点。其关键问题在于地物知识如何抽取、量化、推理，以及先验知识如何同点云深度学习相互耦合。经过四年的实验研究，已完成了既定研究目标，主要成果包括：第一，构建地物知识图谱，实现多维度先验关联的知识表达；第二，设计三维超体素卷积网络，融合知识图谱实现地物候选目标的快速检测；第三，设计三维可变图卷积网络，实现典型地物单体化语义分割；第四，构建 3D-2D 生成式对抗网络，实现了建筑物、道路等典型地物外轮廓的自动提取。研究成果发表了学术论文27篇（其中SCI JCR一区9篇，SCI JCR二区3篇），相关成果已经发表在遥感领域顶级国际期刊ISPRS JPRS、IEEE TGRS、JAG以及遥感国际会议IGARSS上。获批发明专利3项，培养了19个学生。以本项目为基础，申请人还新获批了一项2023年国家自然科学基金面上项目。本项目不仅为地图制图的智能化提供了新的理论支撑，并有力推动了基础测绘、智慧城市的智能感知水平。
