## 中文摘要

任务规划是提高异构多水下机器人系统协同任务执行能力的关键。本项目拟针对现有方法对抗海洋强动态未知环境能力弱、分布式优化困难及在线求解复杂耦合策略效率低的问题，提出可适用性强的对抗性MAB决策任务规划博弈方法。首先，构建异构多水下机器人系统任务规划博弈模型，将系统优化问题转化为单个个体的求解最佳策略响应问题，实现分布式优化。其次，针对在线求解包含未知性的耦合策略效率低的问题，提出离线规划+在线决策学习框架，分摊计算负荷，降低在线计算复杂度。离线规划层考虑海洋环境未知性强的特点，提出离线路径方案设计与评估神经网络算法，提供大量路径方案与评估信息。在线决策层针对海洋环境动态性强的特点，提出分层反思式对抗性MAB决策算法，实现联合任务分配与路径选择快速在线决策。最后，搭建多水下机器人任务规划平台对理论方法进行验证。本研究对解决我国多水下机器人系统大范围执行复杂海洋任务的重大需求具有重要意义。

## 英文摘要

Assignment planning is the key support technology for heterogeneous multi-underwater-robot systems in cooperative assignment execution. This project aims to develop a distributed assignment planning game decision-making scheme based on adversarial MAB theory for heterogeneous multi-underwater-robot systems to solve bottleneck problems such as the strong demand of distributed optimizing structure, the strong dynamic and unknown condition of underwater and the difficulty of solving the online couple strategy. First, an assignment planning game model is formulated for heterogeneous multi-underwater-robot systems. In the proposed game model, the optimization problem of multi-underwater-robot system can be transformed into the best strategy response problem of single underwater robot. Therefore, the problem can be optimized distributedly. Second, an offline planning + online decision-making learning frame is proposed to improve the solution efficiency of this complex couple strategy. The learning frame can apportion the computing load and decrease the complexity of online computing. In the offline planning tier, a neural network-based offline algorithm is proposed to provide path schemes design and estimate. The proposed algorithm can cope with the uncertainties effectively. In the online decision-making tier, a hierarchical reflective form adversarial MAB learning decision-making algorithm is proposed to improve the online decision efficiency of couple task assignment and path planning in the strong dynamic working environment. Finally, a multi-underwater-robot system assignment planning experimental platform is built to evaluate the theoretical methods. This study is of particular significance in addressing the demand for China’s complex wide-range underwater task of multi-underwater-robot systems.

## 结题摘要

与单一或同构的水下机器人相比，异构多水下机器人系统协同作业具有功能互补、灵活多样、工作效率高等突出优点。本项目以异构多水下机器人系统协同作业为背景，针对海洋环境的强未知性、强分布式任务规划需求及强耦合性等问题，对任务规划问题展开研究。.     首先，针对异构多水下机器人系统分布式任务规划需求，考虑水下环境的不确定因素、异构系统等多约束条件，提出了分布式任务规划博弈模型。结合博弈论和智能优化理论，提出了分布式鲁棒拍卖算法和分布式多任务捆绑拍卖算法以对抗水下环境中的不确定性因素、提高任务分配效率，从而高效、低成本地分布式求解多约束任务规划问题。.     其次，针对任务规划问题的搜索空间大以及易陷入局部最优等问题，提出一系列群智能优化算法以提升搜索效率，并有效避免算法陷入局部极值，从而提供高质量的离线任务规划方案。同时，针对水声通信环境的强动态未知特性、节点供能严重受限等问题，结合强化学习理论和深度学习理论提出了多种离线水声通信策略优化算法，提高了水下节点的通信能力和能量效率，进而为异构多水下机器人系统协同作业提供可靠的通信保障。.       再次，针对水下混合任务（紧急-非紧急）时间敏感的差异性、能源携带和硬件计算能力受限以及强动态水下环境干扰等问题，结合自组织神经网络和神经动力学理论提出了一系列在线轻量化任务规划算法，有效降低了计算负荷，实现了混合任务规划问题的一致性求解，节约航行时间和能耗。同时，基于MAB理论提出了一系列轻量化在线水声通信联合优化算法，有效提升了在线通信质量。此外，提出了低能耗、高准确性的轨迹跟踪控制算法，以确保水下机器人能按规划路径航行。.      最后，搭建实验平台并对理论方法进行验证。本项目的研究成果可为异构多水下机器人系统协同分布式任务规划提供理论依据，并为我国海洋的可持续开发提供技术保障。
