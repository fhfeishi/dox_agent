## 中文摘要

迫于多无人机协同作业重大应用需求，图像探测与识别面临“多机应用”的新问题，亟需研究多机图像目标检测与识别基础方法、关键技术和系统原型。本项目按照“模型设计、模型压缩、模型应用”的垂直化技术路线，突破从方法到应用的5个瓶颈。1.针对多机图像“时序、空间、地理”统一配准的难题，提出一种基于无监督学习的“时、空、地”约束模型。2.针对无人机图像“多尺度、弱特征”的问题，提出一种注意力机制引导的Anchor-free目标检测模型。3.针对多机协同目标确认的“跨视场”需求，提出一种基于多任务学习的目标重识别模型。4.针对神经网络模型压缩的“高精度、芯片应用”要求，提出一种基于回溯搜索的网络剪枝模型。5.针对机载应用“小型化、低功耗、大算力”要求，设计一套基于国产AI芯片的机载智能检测识别系统原型。本项目在一定程度上推进多无人机协同探测与识别理论和方法的发展，提高机载视觉智能处理算法、软硬件的成熟度。

## 英文摘要

Forced by the major application requirements of multi-UAV collaborative operation, image detection and recognition are facing with the new problem of "multi-UAV application". It is urgent to study the basic method, key technology and system prototype of multi-UAV images object detection and recognition. This project will break through the five bottlenecks from method to application according to the vertical technology route of "model design, model compression and model application". Firstly，aiming at the difficulty of unified registration of "time series, space, geography" of multi-UAV images, we propose a "temporal, space, and ground" constraint model based on unsupervised learning. Secondly，to solve the problem of "multi-scale, weak features" of UAV images, we design an anchor-free object detection model guided by attention mechanism. Thirdly，for the “cross-field” requirement of multi-UAV collaborative object confirmation, an object re-identification model based on multi-task learning is proposed. Fourthly, due to the requirement of "high precision, chip application" of neural network model compression, a network pruning model based on backtracking search is proposed. Finally, according to the requirement of "miniaturization, low power consumption and large computing power" of airborne application, a set of prototype of airborne intelligent detection and recognition system based on domestic AI chip is designed. To a certain extent, this project can promote the development of theory and method of multi-UAV collaborative detection and recognition, and improve the maturity of airborne vision intelligent processing algorithm, software and hardware.

## 结题摘要

本项目针对多无人机协同探测图像目标检测与识别的基础问题，开展多机探测图像“时序、空间、地理”约束模型、多机探测图像目标检测与重识别模型、神经网络模型轻量化与压缩、基于国产AI芯片的机载智能检测识别系统设计等研究。.取得成果包括：（1）多无人机探测图像“时序、空间、地理”约束模型。①针对无激光测距仪的实时目标位置解算要求，提出了一种基于深度估计和尺度恢复的目标定位方法。②针对多无人机协同目标侦察“时序、空间、地理”对齐问题，提出基于准GCP聚合的约束模型。（2）多无人机协同图像目标检测与重识别模型。①针对小目标检测，提出基于注意力和时空信息的中高空无人机图像小目标检测以及基于多尺度特征和高斯Wasserstein距离的小目标检测模型；②针对小样本目标分类，提出基于元学习和协同注意力的小样本遥感图像目标检测模型以及基于注意力与双分支判别的小样本遥感图像场景分类模型；③针对多机跨视场目标重识别，提出时空约束模型构建方法和基于多分辨率图像的目标重识别方法；④针对多机协同侦察目标预测与行为分析，提出基于紧密耦合卷积transformer的时间序列预测方法和基于分层时空图卷积预测网络的目标行为异常分析方法。（3）深度神经网络模型剪枝与参数量化方法。①针对轻量化模型设计，提出了基于中心点预测的轻量化目标检测模型；②针对低比特网络模型，提出了基于上下文依赖的精确二值神经网络和基于动态阈值和滤波的二值密集预测器；③针对深度神经网络模型压缩，提出了渐进式深度神经网络模型蒸馏方法和基于快速梯度迭代的深度神经网络模型量化方法。（4）基于国产AI芯片的系统原型设计与试验验证。①建立了多类型无人机协同侦察图像数据集。②研发了基于国产AI芯片Hi3559和RK3588两款机载视觉处理器。③算法和硬件系统经过飞行验证，效果良好。.项目研制过程中，项目负责人获评国家级人才项目1项，荣获航空学科科技进步三等奖1项，发表高水平学术论文19篇，申请国家发明专利7项。相关研究成果在多个大院大所和公司推广应用。
