## 中文摘要

在不具备全球定位系统的环境中，为支承空中机器人执行基础设施巡检等自主飞行任务，目前一般基于机载传感进行自主导航。然而，机载传感器大幅增加了机器人负载，从而导致其运动敏捷性以及续航能力显著下降。同时，此类导航技术的运算效率以及鲁棒性仍不能充分满足实际需求。鉴于上述问题主要由传感负载所导致，采用地空协同方式将传感负载迁移至地面机器人，有望从根本上提升空中机器人的自主导航效能。基于这一思路，本项目拟开展多地面机器人对空观测与协同运动规划研究，探索多主动视觉系统的协同观测与运动规划，面向最速飞行/最佳观测的多目标飞行轨迹优化，以及对应的多源信息融合/容错方法。基于上述研究，建立具有高效、敏捷作业任务能力的地空协同观测与运动规划理论方法与关键技术，并构建相应的实验演示系统。本研究成果将有助于空中机器人敏捷高效的服务于桥梁底部、隧道内部等大型基础设施的常规巡检，以及复杂环境中的集群侦查/攻击等任务。

## 英文摘要

This project aims to develop a robust state estimation method for agile flying robots based on a heterogeneous cooperation technique using multiple active observation systems on ground robots. The purpose of this state estimation method is to effectively reduce the sensor and computation complexity on the autonomous flying robot, thus increase its agility and endurance. As more powerful computational unit and sensors can be equipped on ground robots, the robustness of the state-estimation can also be effectively enhanced. To facilitate this development, the feature marking method for the flying robot, which can be fast extract from its background in image processing, will be first investigated. The ground robots with multiple freedom manipulators carrying image capture systems will be also designed for active observation. With such development, the optimal path planning for each ground robot and manipulator will be studied to obtain optimal image capture quality. The state of the flying robot will be preliminarily estimated with the captured image, and multi-information fusion, based on the motion planning and onboard sensing, will be conducted to improve the accuracy and robustness of the state estimation. Considering obstacles and illumination variant in the environment, the fault tolerant estimation based on model predictive method will be investigated, and the multi-agent path planning strategy for active observation will also be studied. Based on the aforementioned state estimation methodology, an integrated robust state estimation framework based on heterogeneous cooperation will be proposed for the agile flying robot.  This framework can be potentially applied for the autonomous inspection of large infrastructure and swarming attacking in a cluttered environment.

## 结题摘要

本项目面向GPS拒止条件下的空中旋翼机器人全自主作业任务，重点研制了鲁棒准确的地空协同定位系统。项目首先设计了面向协同定位的机器人先验特征标记方法，建立了主动视觉系统以及欠驱动空中机器人运动模型，提出了综合考虑观测质量和飞行效率的地空多机器人协同观测与运动规划方法。其次，设计了基于特征标记的多主动视觉系统相对位姿实时解算以及误差分析方法，提出了以提升观测和定位质量为目标的多目标飞行轨迹优化与追踪方法。同时，设计了多机器人主动观测系统多源信息滤波方法，构建异构多源信息质量评价准则，提出自适应容错以及稳定性分析方法，实现观测失效条件下多机器人系统的运动状态预观测以及容错调度规划。最后，基于理论和技术研究成果，开发了全自主地空协同巡检机器人，支撑高效可靠的局部区域自主作业任务。基于本项目所提出的定位、规划技术，为浦江桥隧运营集团、国家电网等单位开发了自主巡检无人系统并取得了良好的应用效果。项目执行期间，共发表33篇学术论文（SCI论文22篇，EI会议论文11篇），申请3项核心技术专利，培养3名博士生、8名硕士生以及8名本科生。指导学生在“智在飞翔”等智能自主飞行比赛中获得全国冠军。项目负责人晋升上海交通大学副教授，并入选上海市科技创新启明星计划。综上所述，本研究项目取得了预期成果，为空中机器人实现高效可靠的局部区域自主作业任务提供了理论及技术支持，同时通过应用示范验证了本研究的应用价值。
