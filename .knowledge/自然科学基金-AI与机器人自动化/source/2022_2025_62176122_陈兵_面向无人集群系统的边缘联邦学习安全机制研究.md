## 中文摘要

随着无人系统不断的发展与进步，各类无人集群系统在国防和民用等重点领域得到了广泛应用。然而，由于无人集群系统所处环境具有高机动和弱连接等特点，传统的网络体系架构和智能学习模型应用于无人集群系统时会面临数据分布不均衡、无人设备计算能力有限等诸多问题。因此，本项目在边缘计算和无人集群系统背景下应用联邦学习机制，从而充分保证无人终端在联邦学习系统中能够进行高效、安全和隐私保护的智能决策服务。首先，本项目拟构建一种高效、鲁棒的边缘联邦学习体系架构。其次，本项目拟设计可靠的无人集群系统安全接入机制，使各无人设备之间可以高效可靠地确立信任关系。再次，本项目拟针对面向无人集群系统的边缘联邦学习模型安全问题，设计高容错的联邦学习算法，进而满足高机动、开放式无人集群系统对智能算法的高可用性需求。最后，本项目拟从数据安全和隐私保护角度出发，充分利用不同实体的协同计算能力，以轻量化开销提升数据安全与隐私保护等级。

## 英文摘要

With the continuous development and progress of unmanned systems, all kinds of unmanned cluster systems have been widely used in national defense, civil, and other key fields. However, due to the characteristics of high mobility and weak connectivity, the traditional network architecture and intelligent learning model will face many problems when applied to the unmanned cluster system, such as unbalanced data distribution, the limited computing power of unmanned devices, and so on. Therefore, this project applies a federated learning mechanism in the background of edge computing and unmanned cluster system, so as to fully ensure that the unmanned terminal can provide efficient, secure and privacy protection intelligent decision-making service in the federated learning system. Firstly, this project intends to build an efficient and robust edge federated learning architecture. Secondly, the project plans to design a reliable security access mechanism for unmanned cluster systems, so that the trust relationship between the unmanned devices can be established efficiently and reliably. Thirdly, aiming at the security problem of edge federated learning model for unmanned cluster system, this project designs a high error-tolerant federated learning algorithm to meet the high availability requirement of an intelligent algorithm for highly mobile and open unmanned cluster system. Finally, from the perspective of data security and privacy protection, this project intends to make full use of the collaborative computing power of different entities to improve the level of data security and privacy protection by reducing the cost.

## 结题摘要

本项目围绕“面向无人集群系统的边缘联邦学习安全机制”这一核心目标，针对无人集群在高机动、弱连接、资源受限和强对抗环境下的智能化需求，系统开展了体系架构构建、安全接入与认证、模型安全机制以及隐私保护技术等研究工作。在体系架构方面，构建了云–边–端协同的边缘联邦学习框架，提出多模态数据融合方法、微服务可靠性增强部署策略以及端–边–云协同决策机制，实现弱连接条件下的稳定训练与高效智能决策。在安全接入方面，提出基于区块链与 aSVC 的轻量级动态认证方案和基于 PUF 的双向认证协议，构建跨域可信身份体系，显著降低资源受限设备的认证开销并提升系统安全性。在模型安全方面，围绕成员推理、模型投毒、属性推理和隐蔽后门攻击等典型威胁，提出主动学习增强的成员推理攻击方法、DefMPA 投毒防御算法、PIAFGNN 属性推理机制以及 StealthFL 后门检测方法，并结合通信干扰场景设计 MACAPF 协同覆盖策略，全面提升联邦学习模型的鲁棒性与安全性。在隐私保护方面，提出组件对齐的异构数据缓解方法、多模态隐私保护框架以及基于模态平衡度量的增量学习样本选择策略，并构建 FedRPN 高效联邦学习框架，实现资源受限条件下的轻量化隐私保护与高效建模。.项目共发表论文 11篇（其中 SCI 期刊 7 篇），授权发明专利 7 项，培养博士研究生 3 名、硕士研究生 5 名。研究成果形成了从体系架构、接入认证、模型安全到隐私保护的完整技术体系，为无人集群系统在复杂环境中的安全智能化应用提供了重要的理论基础与技术支撑，具有良好的工程应用前景。
