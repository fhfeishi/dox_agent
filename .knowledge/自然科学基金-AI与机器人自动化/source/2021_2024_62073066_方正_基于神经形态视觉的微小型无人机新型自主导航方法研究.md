## 中文摘要

现有微小型无人机自主导航系统，多采用标准帧视觉，基于滤波/优化或深度学习的导航方法，在CPU架构处理器上实现自主导航，难以解决高速运动、光照变化和长期适应性等挑战性问题。针对于该问题，本项目拟提出一种全新的自主导航范式，研究利用神经形态视觉、神经形态计算学和神经形态处理器来解决复杂环境中的自主导航问题。首先，模拟生物视觉系统，研究基于神经形态视觉和脉冲神经网络的位姿估计方法，解决运动模糊、时延大等问题；其次，基于类脑导航理论，研究提出神经形态视觉SLAM方法，使得视觉建图更加鲁棒、高效；然后，提出基于神经形态视觉的避障方法，实现仿生的路径规划与导航；最后，基于神经形态处理器，研究实现传感器+导航方法+处理器完全类脑的导航系统。项目意义在于突破现有导航范式，探索一种全新的神经形态视觉导航范式，为最终实现类似自然界飞鸟只利用简单的大脑和视觉、消耗极少能量就能实现丛林中高速飞行、追踪等奠定基础。

## 英文摘要

Most existing Micro Aerial Vehicles use standard frame-based vision sensors, and filtering/optimization/deep-learning based navigation methods running on CPU-architecture processor to realize autonomous navigation, which is difficult to deal with fast-motion, illumination-changing, and long-term adaptation problems. To solve those problems, this project aims to propose a novel autonomous navigation paradigm, which uses neuromorphic vision, neuromorphic computing and neuromorphic processor to deal with autonomous navigation in complex environments. First, mimicking the biological vision system, we propose a novel pose estimation method based on neuromorphic vision and Spiking Neural Networks, to deal with fast-motion, high-latency problems; Second, depending on brain-inspired navigation theory, we propose a neuromorphic visual SLAM method to enable robust and efficient visual localization and mapping; Third, we propose a neuromorphic vision based obstacle avoidance method to realize bio-inspired path planning and navigating; Finally, using neuromorphic processor, we develop a fully brain-inspired autonomous navigation system using neuromorphic vision, algorithms and hardware. This project can potentially break through traditional navigation paradigm and propose a fully novel neuromorphic vision-based navigation paradigm, and lay solid foundation for finally realizing fast flying and tracking in forests as birds by using only simple brain and vision while consuming little energy.

## 结题摘要

传统的微小型无人机自主导航系统，多采用标准帧视觉，基于滤波/优化或深度学习的导航方法，在CPU架构处理器上实现自主导航，难以解决高速运动、光照变化和长期适应性等挑战性问题。针对于该问题，本项目研究提出了一种全新的自主导航范式，研究利用神经形态视觉、神经形态计算学和神经形态处理器来解决复杂环境中的自主导航问题。项目组首先开展了脉冲神经网络和事件数据增强的研究以及基于事件相机的位姿估计问题研究，提出了一种基于扩散模型的不确定性视觉里程计估计方法和二阶段由粗到精的位姿估计方法，使得机器人在高动态范围和快速运动的复杂环境中能够获得更加准确和鲁棒的位姿估计。接着，提出了一种基于前馈高斯的事件相机三维重建方法并针对于闭环检测问题，先后提出了基于端到端人工神经网络、脉冲神经网络以及结合帧相机的的视觉位置识别方法，实现了在极端场景下（运动模糊、炫光）场景下鲁棒和精确的视觉位置识别。同时，开展了基于神经形态视觉的光流和深度估计研究，使得无人机能够较为精确地感知障碍物的距离和运动等信息，为自主导航避障奠定了基础。接着，提出了基于深度强化学习和脉冲神经网络的自主规划导航算法，实现了微小型无人机快速、灵活、鲁棒的导航避障。最后，研究了基于神经形态处理器的全神经形态系统实现与导航方法验证，提出了结合事件相机、脉冲神经网络和神经形态处理器的动态物体检测与异步感知避障方法，实现了鲁棒、高能效的一整套全神经形态自主导航系统，验证了全神经形态自主导航范式的可能性。项目的意义在于突破了传统导航范式，探索了一种全新的神经形态视觉导航范式，为最终实现类似自然界飞鸟只利用简单的大脑和视觉、消耗极少能量就能实现丛林中高速飞行、追踪等奠定了基础。项目执行期间内依托本项目共正式发表论文23篇，其中国内外期刊论文17篇（含IEEE汇刊长文7篇，RA-L论文6篇），国际顶级会议6篇（ICLR、ICRA、IROS）。此外，申请国家发明专利5项，先后共培养研究生21名。
