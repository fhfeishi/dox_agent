## 中文摘要

导航是自然界中许多生物的基本生存技能，是移动机器人的一项基础能力。随着机器人越来越广泛地应用到诸如目标搜寻、货物运载等人类生产生活的各个方面，自主导航越来越成为一项重要技术。然而，现阶段移动机器人的导航能力还达不到许多低等动物的水平，因此如何构建一套稳定可靠的自主导航系统是当下人工智能领域亟待解决的科学难题。本项目从自然界中被称为“导航专家”的昆虫的内在神经结构和导航机理出发，使用稀疏编码、环吸引子等数学理论工具对昆虫导航神经系统进行刻画和功能扩展，构建一套高可靠、低功耗、从传感信息输入到运动控制输出的自主导航闭环系统，并利用微型移动机器人和多模态物理实验平台对所设计的导航算法进行测试和验证，从而为解决现阶段自主导航技术中的科学难题，探索一种崭新的生物似然性研究方法。

## 英文摘要

Navigation is not only a basic and crucial skill of many living creatures in nature, but also a basic ability of mobile robots. With the increasing application of robots in all aspects of human production and life, such as target search and cargo handling, autonomous navigation technology has becoming more and more important. However, at this stage, the navigation ability of mobile robots cannot rival that of many lower animals. Therefore, how to build a stable and reliable autonomous navigation system is a hot scientific problem in the field of artificial intelligence. Starting from the internal neural structure and navigation mechanism of insects called the navigation expert in nature, this project describes and extends the insect navigation nervous system by using mathematical tools such as sparse coding and ring attractors, and then constructs a set of robust, low-power-consumption autonomous navigation system realizing the closed-loop from sensor information input to motion control output, The designed navigation algorithm will be tested and verified by using micro mobile robot and multimodal experiment platform, so as to investigate a new biological plausible research method and technical system to break through the bottleneck of autonomous navigation technology at present.

## 结题摘要

“导航”是移动机器人融入人类生产生活的核心能力，然而其可靠性、能耗与效率仍远逊于自然界中的昆虫。针对这一瓶颈，本项目从被誉为“导航专家”的昆虫入手，旨在探索一套高可靠、低功耗的生物似然自主导航新范式。.项目主要研究内容包括：（1）构建导航计算核心：借鉴昆虫神经结构，利用稀疏编码与环吸引子网络，模拟了多模态信息的贝叶斯最优融合与路径积分机制，形成了鲁棒的空间认知计算框架。（2）实现感知-控制闭环：解决了从原始视觉、地磁等传感信息中实时解算方向/速度等模型输入，并将模型输出的抽象转向指令转化为机器人具体运动控制的关键编解码问题。（3）完成物理验证与平台创新：不仅在轮式、六足机器人上成功实现了算法嵌入与验证，更创新性地研制了世界首个高精度沙漠蚂蚁具身仿真平台I2Bot，为复杂环境下的导航算法测试提供了革命性工具。.项目重要成果与关键数据如下：研究期间共发表高水平学术论文14篇，其中JCR Q1期刊论文7篇（包括神经网络顶级期刊Neural Networks、英国皇家学会界面期刊Journal of the Royal Society Interface等），CCF-C类国际会议论文5篇。核心成果包括：提出了集成目标趋近与碰撞避免的导航模型；开发了纯视觉导航及抗噪声碰撞感知模型；通过系统性比较，证实了生物似然方法在能耗与效率上相较于强化学习等方法的优势；所创建的I2Bot平台已开源，极大促进了具身仿真研究。.本项目的科学意义在于，成功地将生物神经机理转化为可计算、可验证的工程模型，为理解生物智能的本质提供了新颖的计算框架，推动了神经科学、数学理论与人工智能的交叉融合。在应用前景上，所开发的低功耗、高稳健算法为微型机器人、电力巡检、资源受限环境下的自主系统（如太空探测）提供了切实可行的技术路径，具有重要的潜在应用价值。
