## 中文摘要

本项目以具有驱动器故障的柔性机械臂为研究对象，开展其运动控制方法研究。首先，针对具有驱动器性能故障的柔性机械臂，提出一种基于神经网络的普适性控制方法。当系统因驱动器性能故障而存在不同种类输入约束，甚至是混杂型输入约束时，所提方法可以有效克服输入约束对系统的影响，实现系统控制目标；其次，针对具有某一驱动器完全损坏故障的柔性机械臂，提出一种基于动力学耦合的控制方法。当系统某一驱动器完全丧失驱动能力时，所提方法可以利用剩余的驱动器实现系统控制目标；然后，针对具有突发未知驱动器故障的柔性机械臂，提出一种基于模型预测控制的运动控制方法。当系统控制过程中突发未知驱动器故障时，所提方法可以对故障进行在线检测和诊断，并针对故障进行在线调整，实现系统控制目标；最后，通过仿真与实验验证所提控制方法的有效性。本项目的研究将为具有驱动器故障的柔性机械臂提供一套有效的运动控制解决方案，具有重要的理论意义和应用前景。

## 英文摘要

This project focuses on the flexible manipulator with actuator faults and studies the motion control method of the system. Firstly, for the flexible manipulator with actuator performance faults, a universal control method based on the neural network is proposed. This proposed method can effectively overcome the influence of different kinds of input constraints, even the hybrid input constraints, which exist in the system due to actuator performance faults, to realize the control objective of the system. Secondly, for the flexible manipulator with a completely damaged actuator, a control method is proposed based on system dynamic coupling. When an actuator of the system completely fails to work, the proposed method can utilize the remaining actuators to achieve the control objective of the system. Then, for the flexible manipulator with sudden unknown actuator faults, a motion control method is proposed based on the model predictive control. This control method can detect and diagnose the unknown actuator fault online when it suddenly occurs in the system control process, and this control method can make online adjustments according to the fault and thus achieve the control objective of the system. Lastly, the effectiveness of the proposed control methods is verified by simulations and experiments. The research of this project will provide a set of effective motion control schemes for the flexible manipulator with actuator faults, which has important theoretical significance and application prospects.

## 结题摘要

柔性机械臂作为先进机器人系统的关键组成部分，在航空航天、微创医疗、智能制造等领域具有广泛应用前景。然而，其高性能运行高度依赖于驱动系统的可靠性，一旦发生驱动器故障，极易引发控制失效甚至系统崩溃。因此，面向驱动器故障的容错控制研究不仅具有重要的理论价值，更对提升柔性机器人系统安全性与鲁棒性具有迫切的工程意义。本项目围绕三类典型驱动器故障情形开展研究，包括驱动器性能退化引起的持续性输入非线性问题、某一驱动器完全失效导致的欠驱动控制问题，以及运动过程中突发且未知的驱动器故障。针对上述挑战，本项目提出了多种针对性补偿与容错控制策略，并构建了仿真平台与多套实验装置，验证了理论方法的有效性与工程可行性。此外，项目还探索了控制理论在口腔检测机器人、管道巡检机器人及仿人机械手指等原型系统中的应用，为柔性机器人在复杂环境下的可靠运行奠定了技术基础。.经过三年研究，项目全面完成了预定研究目标，在理论方法、实验验证、工程应用及学术成果方面均取得了显著进展。理论上，基于神经网络、滑模控制、扩展状态观测器、迭代学习、模糊神经网络等先进控制方法，提出多类新型容错控制策略，实现了柔性机械臂在多种驱动器故障条件下的高精度位置控制与振动抑制；实验上，分别研制了采用常规电机驱动、新型气动软体驱动以及PVDF压电驱动的柔性机械臂实验平台，并开发硬件在环驱动器故障测试系统，充分验证了方法的鲁棒性与泛化能力；应用上，成功搭建了面向实际场景的柔性机器人原型系统，展示了研究成果的应用潜力。在成果产出方面，项目共发表标注本项目资助的学术论文19篇（其中期刊论文16篇），申请国家发明专利6项（已授权3项），登记软件著作权4项，培养硕士研究生8名、博士研究生2名。此外，项目负责人积极投身学术交流，多次在IRCE 2023、中国控制会议（CCC）等国内外高水平学术会议作报告，并入选“武汉英才计划-优秀青年人才”和湖北省青年科技人才培养专项；同时，受邀担任《Journal of Bionic Engineering》期刊青年编委，进一步提升了项目的学术影响力。
