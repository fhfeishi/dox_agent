## 中文摘要

基于视觉传感器实现工业机器人对三维目标的分类与位姿估计是进行目标抓取任务的基础研究。传统三维目标分类与位姿估计技术存在精度低、数据处理困难和实时性较差的问题。同时，数据样本量和标注也制约了深度学习算法在工业机器人中的应用，造成其无法满足实际工业生产的要求。本项目拟在深度学习理论和机器人操作系统相结合的方面，从目标表征模型和学习算法构造层面解决三维目标分类和位姿估计问题。首先，探索深度学习理论在三维目标问题的适用性、泛化性和扩展性，结合机器人操作系统研究数据集采集和自动标注方法，揭示三维物体位姿估计任务对数据选择的设计规律。其次，从特征融合角度，建立多模型多特征融合的深度神经网络网络模型，为三维目标表征方法提供理论支撑和技术参考。进一步地，通过设计和优化深度目标分类和位姿估计方法框架，提高机器人在三维目标上的模型精度、鲁棒性与泛化性，最终解决在目标抓取任务中的应用问题。

## 英文摘要

The task of classification and pose estimation for 3D object based on visual sensor is the basic research of object grasping. Traditional 3D object classification and pose estimation technology have problems such as low accuracy, difficult to processing data and poor real-time performance. Meanwhile, the sample capacity and annotation restrict the application of deep learning algorithm in industrial robots, resulting in its inability to meet the requirements of actual production. This project intends to solve the problems of 3D object classification and pose estimation from the construction of object representation model and learning algorithm based on combination of deep learning theory and robot operating system. Firstly, we wang to explore the deep learning theory on the applicability, generalization and expansibility. Combined with the robot operating system, the dataset acquisition and automatic annotation methods are studied to reveal the design law of data selection for 3D object pose estimation. Then, a deep neural network model of multi-model and multi-feature fusion is established to provide theoretical support and technical reference for 3D object representation methods from the perspective of feature fusion. Further, we improve the model accuracy, robustness and generalization of the robot on the 3D object by designing and optimization the depth object classification and pose estimation framework. Finally, we want to solve the application problem in the object grasping task. This project condenses the key scientific problems from the actual production of industrial robots, and uses the combination of deep learning theory and robot operation system to break through the key technical barriers of 3D object data processing, model representation and prediction accuracy, so as to provide preconditions for the application of intelligent robots in the future.

## 结题摘要

本项目针对复杂工业场景下工业机器人三维感知与交互任务中的关键问题进行了若干研究，主要围绕虚拟合成数据生成、三维点云目标特征提取与姿态估计方向，对工业场景下机器人装配过程中存在的实际问题建立相应模型，完成相关任务，并提出了系列算法，如下：（1）针对真实工业场景下数据采集困难、人工标注成本高的问题，提出了基于Isaac Sim的合成数据集自动标注算法，实现脚本化动态生成大规模精确标注数据，并通过遮挡关系建模与样本筛选提升标注有效性。同时，提出基于几何先验的注意力RPN（Region Proposal Network）小样本目标检测算法，结合对比学习策略利用少量真实样本进行二次训练，提升小样本条件下的检测召回与精度。（2）针对传统基于NeRF（Neural Radiance Fields）的方法重建结果语义缺失、几何表达隐式且难以编辑复用的问题，开展了融合语义先验与神经辐射场的显式三维资产重建方法研究，输出结构化、可编辑、可复用的三维几何资产，为下游姿态估计任务提供支撑。围绕工业零件弱纹理、对称性强、几何细节复杂导致姿态估计精度与稳定性不足的问题，研究了基于三维点云几何表达的工业零件6D姿态估计目标特征提取网络，形成以几何结构建模为核心的技术路线。（3）针对小尺寸工件姿态估计精度低的问题，提出了基于多层残差感知的点云6D姿态估计方法，采用编-解码器结构与多尺度特征融合策略，实现更高精度与更快推理速度。同时，针对工业场景下可变形物体操作难的问题，采用对比学习方法联合优化视觉表征模型和动力学模型，构建多分支拓扑结构的编码器，提高模型的表征能力，增大工业场景下可形变物体的任务成功率。本项目的开展对提升复杂工业场景下工业机器人三维感知与操作能力具有重要的借鉴意义，为工业场景下目标抓取、装配与智能交互等应用提供了更好的技术支持。本项目当前已发表论文4篇（中科院二区期刊论文1篇，发表期刊为IEEE Transactions on Intelligent Transportation Systems；会议论文3篇）。本项目共申请并受理中国发明专利2项，其中授权2项。培养硕士研究生3人。
