# 前端审查：功能、操作、界面、文案与动效

本文是审查记录，只提建议，不改要求。首页与领域分析的交互层级、配色、排版已有详细方案（[领导体验优化 §4](tasks/领导体验优化-20261026/README.md)，状态：未开始），本文不重复，只把它扩展到全站，并补上其他页面的问题。

## 结论

功能齐全，主要问题是**同一件事有多个入口、多个名字，以及界面暗示不统一**。用户找功能时要猜，看界面时要分辨哪些能点。下表按“对文档管理者每天工作的影响”排序。

## 5. 动效

现状（`globals.css` 与 `domain-lens.css`）：约 20 种时长（100、120、140、150、160、180、200、240、250、260、300、320、420、520、620、650 ms……），5 种缓动曲线，只有 `--ease-panel` 一个令牌；减少动态偏好只在两个文件里处理。

建议：

| 令牌 | 时长 | 用于 |
|---|---|---|
| `--dur-quick` | 120 ms | 悬停、按下、勾选 |
| `--dur-small` | 200 ms | 浮层、下拉、提示出现 |
| `--dur-panel` | 320 ms | 右侧滑出、抽屉、页签内容切换（现有滑出框已是 320 ms） |
| `--dur-layout` | 520 ms | 图表、谱系展开等布局变化（02 谱系已按此实现） |

- 进入统一用一条缓出曲线（如 `cubic-bezier(.16, 1, .3, 1)`），退出用更短时长、缓入；
- 一个全局规则处理 `prefers-reduced-motion: reduce`：动画时长归零，直接到终态；
- 引导遮罩不做全屏淡入淡出（Q3）；
- 首页轮播 7 秒自动翻页、悬停暂停，保留。
