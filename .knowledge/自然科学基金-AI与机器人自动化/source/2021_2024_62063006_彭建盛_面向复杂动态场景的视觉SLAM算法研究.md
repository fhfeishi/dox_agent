## 中文摘要

视觉定位导航技术一直是机器人领域的研究热点，具有低成本、信息丰富等优势。但实际应用场景中常常存在动态物体，从而导致传统视觉定位导航技术出现定位漂移和特征丢失等现象。本课题主要面向实际应用需求，研究复杂动态场景下的低成本视觉SLAM定位导航关键技术。针对动态物体数量多、占比大、传统视觉SLAM难以使用的场景，以深度学习方法和计算机视觉方法为主要工具，研究基于学习推理的动静态物体分割模型，对图像中的动静态物体进行识别分割，通过引入语义信息和动态性信息来使模型获得更准确稳定的检测结果，再将有效的静态信息应用于视觉SLAM当中；针对环境发生变化，传统视觉SLAM难以识别闭环，地图对动态环境不具备自主更新功能等问题，通过动态性信息构建更适用于动态环境的地图模型以及地图更新策略，并完善闭环检测算法，降低环境中物体位置改变对视觉重定位的影响，最终实现可用于不同复杂动态场景下的高稳定性视觉SLAM算法。

## 英文摘要

Visual positioning and navigation technology has always been a research hotspot in the field of robotics, which has the advantages of low cost and rich information. However, when there are dynamic objects in the practical application environment, traditional visual positioning and navigation technology often has such problems as positioning drift and feature loss. This project focuses on the practical application requirements, and dose research on the key technology of low-cost visual SLAM positioning and navigation in complex dynamic scenes. For scenes with large number and proportion of dynamic objects and inability of traditional visual SLAM to work, we use deep learning method and computer vision method as the main tools to do research on the dynamic and static object segmentation model based on learning reasoning, to recognize and segment the static and dynamic objects in the image. By introducing the semantic information and dynamic information, the model can get more accurate and stable detection results. Then put static information into visual SLAM. When the environment changes, the traditional visual SLAM is difficult to identify loop closure, and the map does not have self-renewal function for dynamic environment. In order to solve these problems, a map model and a map update strategy which are more suitable for dynamic environment are constructed by dynamic information, and a loop closure detection algorithm is improved to reduce the impact of object position change on visual relocation in the environment. Finally, a high-stability visual SLAM algorithm is realized for different complex dynamic scenes.

## 结题摘要

视觉定位导航技术中，由于实际应用场景常常存在动态物体，从而导致传统视觉定位导航技术出现定位漂移和特征丢失等问题。本项目针对该问题，结合应用实际场景，开展复杂动态环境下的场景感知与理解、人机交互、视觉SLAM等技术研究，突破面向应用的复杂动态环境视觉感知、导航、自然交互、智能控制等核心技术，进而开发全天候应用的视觉导航自主移动系统，并实现在终端配送等领域的应用示范。.开展的研究包括：复杂动态场景感知与建图技术、人机交互及规划控制技术、整机应用系统集成开发三个层面。在技术方面，实现了（1）攻克室内外、全天候、动态环境下的机器人视觉定位、建图与自主导航规划技术，实现像素级的视觉语义分割并构建含语义的地图，建图与定位精度高于10cm；（2）自然化人机交互：具备人体识别、人脸识别、语音交互、触屏交互等多种互动手段；（3）研发了无人车实验平台，具备自主导航移动功能，能够实时确定自身在环境中的位置，载重不低于30kg，最大运行速度不低于3m/s，爬坡角度不低于10度。
