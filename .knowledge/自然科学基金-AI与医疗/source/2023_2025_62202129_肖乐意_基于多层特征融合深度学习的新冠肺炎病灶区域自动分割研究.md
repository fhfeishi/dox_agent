## 中文摘要

当前新冠肺炎疫情形势仍然严峻，快速、准确地检测出新冠肺炎患者对疫情防控具有重要意义。研究表明：与核酸检测相比，肺部医学影像诊断是一种更安全、廉价、高效的新冠肺炎检测技术。但是，现有方法的病灶分割结果模糊，影响了诊断效果。对此，本项目拟围绕准确分割新冠肺炎病灶区域的深度学习方法开展研究：融合各层边沿细节信息，构建一种带边沿指导思想的多层特征融合深度学习网络模型；考虑像素的空间相关性，以最大化真实和预测分割图像间的高维分布相似性为目标，设计一种兼顾像素和结构信息的新型损失函数；结合分层拓扑结构、邻域思想和自适应策略，提出一种分层拓扑结构自适应邻域信息引力搜索算法，优化损失函数以获得最优网络参数。目的是研究出适于分割新冠肺炎病灶区域的深度学习网络及算法理论，为基于医学影像检测新冠肺炎提供新思路，丰富深度学习和智能优化算法理论。因此本项目具有重要的实际应用需求和良好的理论研究价值。

## 英文摘要

The current COVID-19 situation is still severe, and the rapid and accurate detection of COVID-19 patients is of great significance for epidemic prevention and control. Studies have shown that compared with nucleic acid detection, lung medical imaging diagnosis is a more safe, cheap, efficient COVID - 19 detection technology. However, the existing segmentation methods have the problem of fuzzy segmentation, which seriously affects the diagnosis effect. In this regard, this project intends to conduct research on deep learning networks that can accurately segment the focal regions of COVID-19: A multi-layer feature fusion deep learning network architecture with edge guidance is constructed by integrating edge details of each layer. Considering the spatial correlation of pixels and aiming at maximizing the high-dimensional distribution similarity between the real and predicted segmented images, a new loss function considering both pixel and structure information is designed. Combining layered topology, neighborhood idea and adaptive strategy, a layered topology adaptive neighborhood information gravity search algorithm is proposed to optimize the loss function and get the optimal network parameters. The purpose is to develop a deep learning network and its algorithm theory suitable for segmentation of COVID-19 focal regions, provide new ideas for COVID-19 detection based on medical images, and enrich the algorithm theory related to deep learning and intelligent optimization. Therefore, this project has urgent application demand and good theoretical research value.

## 结题摘要

医生通过人工分析图像并进行诊断往往效率较低，在新冠肺炎等突发疾病大规模爆发时不仅耗费巨大的人力和物力，还会造成医疗资源紧张。在人工智能快速发展的时代背景下，研发智能医学图像处理、分析和诊断技术具有重要意义。对此，鉴于图像分割在医学图像分析和诊断中起着重要作用，本项目围绕深度学习的医学图像分割开展了深入研究。鉴于医学图像往往边缘界限模糊、分辨率差，易导致病灶区域分割准确性低，提出了一种了弱边缘与上下文特征深度语义融合的自动分割法；为兼顾分割模型对全局信息的感知能力和对局部特征的挖掘能力，构建了一种基于残差连接和双重注意力机制的U-Net图像分割法；为更好地融合不同尺度特征，提出了一种融合多级残差卷积的上采样跨层连接网络-注意力增强的可分离残差网络；为减少特征冗余、提高模型效率，提出了一种阶跃型引力搜索算法，并将其用于模型的特征选择中；为提高优化算法的性能，通过对局部信息引力搜索算法进行改进，提出了一种基于分层结构的邻域信息引力搜索算法；鉴于特征选择对提高肺炎分类精度与速度具有重要影响，提出了一种基于分解结构多目标鲸鱼优化算法(MOWOA-D)的肺炎特征选择与检测方法。对分割模型的研究设计出尽可能精确的分割模型，特征选择与优化则尽可能地降低特征冗余以提高模型效率，二者从不同角度提升了模型的分割性能。通过对该项目的研究，目前已发表SCI期刊论文6篇，获授权国家发明专利1项，指导硕士毕业生2人，取得了项目预期的成果。
