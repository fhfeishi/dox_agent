## 中文摘要

无人机视觉数据中，目标的绝对尺度和相对尺度更小。深度学习方法在通用目标检测领域取得卓著成效，但是，由于图像尺度缩放、卷积特征提取、锚点匹配和小目标分类等存在不足，很难应对无人机视觉目标检测。本项目提出：研究物距感知图像缩放模型，应对单尺度和金字塔图像缩放存在尺度多样性、计算复杂和引入虚警等问题；研究特征尺度由小至大的倒卷积网络获取深层高分辨率特征，解决浅层特征感知野小，表征力不足，而由深至浅增强浅层的特征融合方式不适合大目标少见的无人机视觉场景；研究热图检测框架，设计中心热图训练网络，回归目标中心及宽高，应对锚点匹配在模型泛化、小目标正样本多样性和小目标初始定位等方面存在的不足；研究利用目标语义背景和语义关联的辅助分类方法，应对无人机视觉图像背景混杂、模式多变；研究硬件感知神经结构搜索方法，设计利于小目标检测的搜索空间及自动压缩/优化模型的算法。部署目标检测系统，推进无人机视觉应用的发展。

## 英文摘要

In UAV vision data, objects usually have smaller absolute scale and relative scale. Deep learning methods achieved remarkable results in general object detection field. But it’s difficult to cope with UAV vision object detection due to drawbacks on image scale resizing, convolution feature extraction, anchor matching, and small object classification etc. This project proposes and implements activities as below. 1) Study distance-aware image scaling model to deal with some problems as scale diversity from single scale resizing, and computational complexity and more false alarms from image pyramid method. 2) Study reverse network to extract features from small scale to large scale and obtain deep high-resolution feature map. It makes a detector not use shallow features with small receptive field and weak representation ability or not introduce a bypath to aggregate features from deep to shallow, which is invalid for UAV aerial scenes that lack large objects. 3) Study a heat-map based detection framework and design a central heat-map to train network that can regress to an object center and its width and height, which solves drawbacks of anchor matching on model generalization, small positive sample diversity, small object initial locating, etc. 4) Study semantic auxiliary classification model. Use semantic background and semantic relationship to classify small objects and be more robust against chaotic background and modality variation in UAV vision images. 5) Study hardware aware neural architecture search method; build a search space and an automatic model compression/optimization algorithm suitable for small object detection. Deploy the object detection system, and develop UAV vision applications.

## 结题摘要

在低空无人机视觉数据中，小目标占比更多，平均分辨率更低，绝对和相对尺度更小，检测难度更大。深度学习在通用目标检测领域已取得卓著成效，但是，由于在图像尺度缩放、卷积特征提取、锚点匹配和目标分类等方面不能较好适配小目标，无人机视觉目标检测面临严峻挑战。经历4年的研究工作，本项目已完成立题任务书中列述的主要研究内容，在小目标特征提取、损失函数设计、模型优化及其技术应用等方面取得优异成绩，目前在国内外顶级期刊和会议发表高水平学术论文19篇、获得国内发明专利9件，软件著作权1个。项目成果对推动低空无人机视觉目标检测技术的发展、应用起到了积极的推动作用。项目代表性成果包括：(1)提出物距感知模型。划分物距等级进行图像缩放和裁剪，缓解目标尺度多样性引发的计算开销庞大、虚警过多等问题；基于尺度感知插值算法放大小目标，减少目标漏检。(2)针对浅层特征感知野小及表征力不足，而由深至浅增强浅层特征的方法往往反而削弱浅层特征表征能力的问题，提出多层级特征融合方法，在有效获取高分辨率特征的基础上保持语义类别信息，提高主干网络的小目标表征能力。(3)针对锚点匹配不利于模型泛化、样本多样性及其初始定位等问题，提出锚点自适应采样方法，设计可伸缩椭圆或概率图采样RoIs，避免遗漏小目标。(4)针对无人机视觉场景背景混杂、目标外观模式多样化的挑战，提出基于语义上下文的特征增强方法，利用背景语义和目标间的关联语义提高目标分类精度。(5)提出增强型局部自注意力(ELSA)显著提高模型性能(包括精度和效率)。将Hadamard注意力引入Hadamard积作用于局部区域，同时保持高阶映射；利用Ghost Head将注意力图与静态矩阵相结合，增加通道容量。(6)提出解耦动态滤波器(DDF)缓解CNN两大缺陷并显著提升网络性能。将深度动态滤波器解耦为空间动态滤波器和通道动态滤波器，模型参数量减少，且用DDF替换分类网络中的标准卷积，网络性能显著提升。
