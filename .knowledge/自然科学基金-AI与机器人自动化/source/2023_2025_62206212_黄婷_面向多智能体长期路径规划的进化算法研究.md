## 中文摘要

多智能体路径规划是保障多智能体系统在无人智能仓储中运作的重要底层技术，然而现有相关方法忽略了系统运行的长期性，难以满足多智能体长期执行任务的实际需求。本项目拟开展以进化算法为核心的多智能体长期路径规划研究：首先针对现有方法存在集中式计算的局限性，从微观层面提出基于图神经网络的分布式进化路径规划算法，分布式学习空间特征，规划高效有序的多智能体路径；然后针对现有方法存在快照式优化的局限性，从宏观层面提出基于小生境技术的持续进化路径规划算法，复用当前路径信息，持续规划整体性能最优的多智能体路径；最后提出微观-宏观协同的分布式计算、持续寻优的进化路径规划算法，实现面向无人智能仓储的多智能体长期路径规划应用，为多智能体在多机协作、全天候运作的无人智能仓储的高效运行提供技术支撑。

## 英文摘要

Multi-agent path planning is an essential underlying technology to ensure the operation of multi-agent system in unmanned intelligent warehouse. However, the existing methods ignore the lifelong characteristic of multi-agent path planning. Therefore, the existing methods are difficult to satisfy the real-world requirement of lifelong multi-agent execution. This project aims at the research on lifelong multi-agent path planning with evolutionary algorithms: First, considering the limitation of centralized computing in existing methods, from a micro perspective, a graph neural network based distributed evolutionary path planning algorithm is proposed, to distributed learning the spatial features, so as to plan efficient and orderly multi-agent path; then, considering limitations of snapshot optimization in existing methods, from a macro perspective, a niching technique based continuous evolutionary path planning algorithm is proposed, to re-utilize the current path information, so as to continuously plan the multi-agent path with the best overall performance; finally, a distributed and continuous evolutionary algorithm of micro-macro coordination is proposed to realize the lifelong multi-agent path planning application for unmanned intelligent warehouse, and provide technical support for the efficient operation of multi-agent system in the unmanned intelligent warehouse with multi-machine collaboration and all-day operation.

## 结题摘要

本项目致力于多智能体长期路径规划领域的前沿研究，针对现有方法在长期运行场景下普遍依赖集中式计算、快照式优化以及难以兼顾系统规模与整体性能等问题，开展了面向多智能体的分布式路径规划与持续优化方法研究。围绕多智能体路径规划在计算效率、整体优化和实际可用性方面的关键挑战，项目从微观协同建模、宏观持续优化以及应用验证三个层面系统推进相关算法与方法研究。.首先，项目从微观层面研究了面向多智能体长期路径规划的分布式与协同方法，通过结构化建模和局部信息利用，降低对集中式计算和通信资源的依赖，提升路径规划效率和执行有序性。其次，针对长期路径规划中快照式优化难以保持整体性能的问题，项目引入小生境机制，研究了基于持续进化的路径规划方法，通过解空间划分、竞争与协作关系建模以及路径信息复用，实现多智能体长期路径规划过程中的整体性能优化。进一步，项目将上述方法应用于典型长期运行场景，对分布式执行、持续优化和系统鲁棒性进行综合验证，证明了相关方法在任务持续到达和环境不确定条件下的有效性和稳定性。相关实验结果表明，所提出的方法在大规模场景中可支持高达500个智能体实现无冲突移动，具备良好的可扩展性。..本项目共发表标注本项目基金号的国际期刊和会议论文12篇，其中SCI检索论文8篇、IEEE Transactions系列国际高水平期刊论文4篇、中文核心期刊论文1篇。相关研究成果公开国家发明专利10项，已获得授权4项。通过本课题的研究培养/联合培养研究生7名。本项目已圆满完成预期研究任务。
