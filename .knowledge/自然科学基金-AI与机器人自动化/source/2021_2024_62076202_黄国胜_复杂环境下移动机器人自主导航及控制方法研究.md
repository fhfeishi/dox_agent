## 中文摘要

复杂场景要求智能机器人快速稳定的方式到达目标点完成既定任务，同时要有稳定精确的控制动作作为保证。本项目旨在将深度强化学习、迁移学习、分层学习理论以及注意力机制思想引入到智能机器人系统中，研究基于深度强化学习的智能机器人导航及控制方法。首先研究特定局部稀疏奖励环境下智能机器人无图路径导航方法，建立好奇心驱动的内在奖励模型，鼓励机器人在未知环境找到合理路径；接着通过教导模仿、深度学习机器人行为，研究完备动态环境机器人全局路径规划。进而研究基于注意力机制的机器人视觉伺服动作控制优化和基于分层强化学习的机器人任务泛化；最后通过相似域迁移学习，完成仿真到实物的模型移植，避免过度学习，提高学习效率。.      研究工作针对工业、运输及军事等领域机智能器人应用的迫切需求，实现智能机器人高效有序的导航及控制方法，为智能机器人自主导航及控制技术研究提供了新思路。

## 英文摘要

Behavioral control of intelligent robots among the different mobile platforms have been widely investigated for complex tasks, requiring move faster towards the desired position to achieve the predefined task under the guarantee of an efficient action-control system. To develop a more advanced navigation and control strategy with a deep reinforcement learning method, this project investigates a robotic prototype system integrating the deep reinforcement learning, transfer learning, layered learning, and attention mechanism. Firstly, to address the map-less navigation challenge in a sparsely partial rewarded environment, this project develops a curiosity-driven navigation planner with intrinsic reward, encouraging a mobile robot to search a reasonable path in unstructured environments with the uncertainties. Then, a behavior model using imitation learning and deep learning is developed for the mobile robot to achieve a complete global path planning. Furthermore, this project investigates a robotic visual servoing architecture employing an attention mechanism to improve the action planner and the task model is extended by a hierarchical reinforcement learning method. Finally, transfer learning is used to transfer knowledge from the simulation to a similar but different real-world robotic systems. A transfer mechanism based on a similar domain allows the robot to obtain a higher learning efficiency without considerable learning cost. This project focuses on the urgent needs on support for the industry, transportation, and military to develop an efficient and orderly navigation and control method for intelligent robots. This research project can provide a new solution for the development of autonomous navigation and control technology.

## 结题摘要

与人工智能结合的智能机器人成为当今世界的研究热点，如何让机器人具有自主学习能力是新一代智能机器人区别于上一代机器人的重要特征。智能机器人研究面临监督学习的过拟合与数据收集标注耗时、机器人强化学习中奖励稀疏与维数灾难、机器人动作自适应智能控制中学习效率等问题，本项目结合深度强化学习、迁移学习、注意力机制等思想进行深入分析，重点研究了复杂环境下机器人自主导航与智能避障。.  首先，为提升机器人自主探索能力，设计了基于正向/逆向模型预测误差的内在奖励机制，提出了基于邻域好奇心探索（NCE）的算法；其次，研究机器人端到端导航方法，通过结合LSTM和稀疏激光测距数据提出了改进A3C算法，增强了模型的鲁棒性；随后，为应对复杂环境下的机器人避障问题，提出了融合里程计数据的改进Hector SLAM方法，并基于此提出了子目标划分路径规划方法，同时结合模仿学习和逆强化学习实现了行为融合；再者，将注意力机制用于机器人控制优化，设计了基于图像状态提取、Dyna算法、自模仿强化学习的控制方法，提出了基于Transformer的智能控制方法；最后，为提高学习效率和泛化性能，提出了基于横向迁移的机器人迁移学习控制策略，并提出基于分层架构的机器人技能学习框架和面向实用性的无监督学习方法等。项目成果具有巨大的实用价值，缓解了以往机器人控制和导航难题，极大地推动了智能机器人在无人工厂、智能仓库等实际场景的应用。.  项目资助发表和录用论文26篇，其中SCI期刊论文25篇、国内顶级学报论文1篇，包括IEEE Transactions on Cybernetics、IEEE Transactions on Fuzzy Systems、IEEE Transactions on Automation Science and Engineering、IEEE Transactions on Industrial Informatics、IEEE Transactions on Systems, Man, and Cybernetics: Systems等国际顶级期刊论文9篇。项目负责人以第一作者/通讯作者发表论文9篇。项目研究成员授权中国发明专利1项、中国台湾发明专利2项，取得软件著作权2项。项目研究成员获陕西省计算机学会自然科学二奖1项、2023年宝钢优秀学生奖特等奖1项（全国仅25人）。
