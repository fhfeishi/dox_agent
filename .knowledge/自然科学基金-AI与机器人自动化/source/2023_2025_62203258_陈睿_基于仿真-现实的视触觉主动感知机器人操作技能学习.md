## 中文摘要

视触觉融合的机器人操作技能学习利用多模态信号提取表征进行决策，相比于单一模态信号，提高学习效果与鲁棒性。针对现有方法需要大量现实交互数据以及固定视觉传感视角难以观测动态交互场景信息的问题，本项目受人类交互认知决策过程启发，研究基于仿真-现实的视触觉主动感知机器人操作技能学习，以减少对现实交互数据的依赖，提高观测效率和任务成功率。主要研究内容包括：针对视觉传感和触觉传感的仿真-现实差异问题，研究基于几何先验的仿真-现实联合学习三维传感方法和基于贝叶斯优化的有限元非均匀网格智能划分和参数辨识方法；针对固定视觉传感视角问题，探索构建视触觉传感器主动调整策略以及研发基于电动可调焦透镜的三维视觉传感器，能够根据当前交互状态主动调节传感器的位姿、视场范围等参数；进而建立一套视触觉机器人操作技能学习仿真平台及硬件实验平台，对所提理论和方法的可行性进行验证，为未来自主机器人的应用提供可行的技术路径。

## 英文摘要

Compared with single-modality, robot manipulation skill learning based on visual and tactile sensing can extract information for policy learning from multi-modal observations, leading to enhanced performance and robustness. However, existing methods require a large amount of real interaction data, and they all use a fixed visual sensor that cannot observe all the necessary information from the dynamic scene. Inspired by the human interactive cognitive decision-making process, this project studies Sim2Real robot manipulation skill learning based on active visual and tactile sensing. It can reduce the dependence on real interaction data and improve the observation efficiency and task success rate. The main research contents include: Aiming at the simulation-reality gap for visual and tactile sensing, mixed-domain learning-based stereo using shape priors and FEM non-uniform meshing and parameter identification based on Bayesian optimization are studied; Aiming at the problem of fixed visual sensing perspective, active visual and tactile sensing policy learning and a novel active stereovision sensor based on electrically tunable lens are studied, which can actively adjust the pose, field of view and other parameters of the sensor according to the current interaction state; furthermore, a visual-tactile robot manipulation skill learning simulation platform and hardware experiment platform are established to verify the feasibility of the proposed theory and method, so as to provide a feasible technical path for the application of autonomous robot in the future.

## 结题摘要

面向复杂操作与高精度装配等接触丰富任务中机器人感知不充分、仿真—现实差异大、技能迁移困难等关键问题，本项目以提升机器人操作精度与鲁棒性为核心目标，系统开展了基于仿真—现实的视触觉主动感知与操作技能学习研究。项目围绕三维视觉感知、触觉感知建模以及感知—决策协同优化等方面，构建了支撑高精度机器人操作的理论与方法体系。.在视觉感知方面，针对透明、高反光等复杂光学特性物体难以准确建模的问题，提出了基于光线追踪的主动双目三维视觉传感器仿真平台以及融合几何先验的仿真—现实联合学习三维重建方法，实现了复杂场景下高精度三维感知与六自由度位姿估计。为解决触觉感知中弹性体大变形与仿真精度不足的问题，构建了基于有限元方法与增量势能接触模型的通用触觉仿真平台与在线域适应迁移框架，显著提升了触觉策略的仿真—现实迁移性能，在微米级间隙装配等高精度任务中实现了高成功率的零样本仿真到现实迁移。.项目执行期间，完成了既定研究目标，发表多篇高水平 SCI 论文，申请并授权多项发明专利。相关研究成果为机器人在复杂环境下实现高精度、强鲁棒性的操作与装配提供了重要的理论基础和技术支撑，具有良好的学术价值和应用前景。
