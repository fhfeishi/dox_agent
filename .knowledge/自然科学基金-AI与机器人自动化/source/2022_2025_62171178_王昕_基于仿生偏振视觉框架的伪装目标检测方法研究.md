## 中文摘要

聚焦伪装目标检测这一具有挑战的计算机视觉任务，本项目以生物偏振视觉机理为仿生基础，以偏振信息的获取、表征与处理为探索主线，在课题组的前期相关工作基础上，将仿生偏振视觉方法与机器学习技术进行有机结合，开展“视觉感知-信息表征-神经计算”融合统一的模型与方法研究。分析生物复眼阵列的拓扑分布、先验映射及自适应调节机制，建立仿生自适应预处理的偏振信息结构化感知模型；分析偏振刺激的响应图谱，定义仿生的偏振信息表征空间，建立符合生物视觉逻辑的“偏振距离”信息表征模型；分析偏振视觉神经系统的多层级传递特性和与其他视觉信息交叉响应的约束关系，建立多维度视觉信息融合的层次化处理模型；构建一定规模的规范化伪装目标偏振图像数据集，在此基础上建立全新的伪装目标检测方法和神经网络框架。本项目可拓宽伪装目标检测的研究思路，有望实现理论和技术的新突破，相关成果在军用和民用领域都具有广阔的应用前景。

## 英文摘要

Focusing on the challenging computer vision task of camouflaged object detection, this project is going to construct model and algorithm that integrate visual perception, information representation and neural computing by combining bionic polarization vision method and machine learning technology. With the mechanisms of polarization vision in animals as bionic basis and the acquisition, representation and processing of polarization information as main research line, this project consists of four tasks based on our previous research. Firstly, we are going to establish a bionic adaptive pre-processing polarization information perception model by introducing the topological distribution, intrinsic mapping and adaptive adjustment mechanism of compound eyes. Secondly, we will build a ‘polarization distance’ information representation model matching the logic of animal vision in the bionic polarization information representation space by analyzing the response map of polarization stimulus. After that, we are going to establish a hierarchical processing model that integrates multi-dimensional visual information by analyzing the multi-level transmission characteristics and the constraint relationship with other visual information of the polarization visual nervous system. At last, we will build a standardized polarization camouflaged object dataset, as well as a new neural network framework for camouflaged object detection. The outputs of this project will enrich the research ideas of camouflaged object detection and realize new breakthroughs in both theory and technology. The new model and algorithm are believed to have broad application prospects in both military and civilian fields.

## 结题摘要

本课题围绕利用偏振信息解决伪装目标检测中的关键科学问题，聚焦偏振信息获取、表征与处理的研究主线，借鉴生物偏振视觉机理，构建了“视觉感知 – 信息表征 – 神经计算”相融合的仿生智能信息处理模型与方法体系。构建了基于复眼阵列拓扑分布的偏振信息感知模型，实现了视觉感受野内目标与背景信息的结构化获取，并完成了基于自适应信息重构的偏振图像预处理；提出了仿生多通道“偏振距离”信息表征模型，建立了符合生物视觉逻辑的偏振信息表征空间，有效描述了偏振态的差异化特征；设计了多维度视觉信息融合的层次化处理模型，模拟了偏振视觉神经系统的多层级结构与信息处理机制。在此基础上，课题构建了首个面向偏振伪装目标检测的数据集PCOD_2000，设计了适配偏振图像数据特性的深度学习框架与模型，并开展了与当前主流方法的对比验证分析。本课题的系统性研究工作拓展了伪装目标检测的研究思路，在理论方法和技术实现上取得了突破，为区分颜色、纹理及结构高度相似的目标与背景提供了新颖且有效的科学手段，显著提升了检测的准确性与鲁棒性，推动了仿生偏振视觉研究的发展。相关成果可应用于国防军工、工业检测、生态防护、地质勘探及医学影像分析等领域，为国家安全与经济发展提供重要支撑。
