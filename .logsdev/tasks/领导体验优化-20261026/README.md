### 2.1 交互层级与配色（`audit.cjs`，1440×900）

具体问题：
- **选中状态有 5 种写法**：首页横条用浅蓝底，首页卡片用深色边框，视角按钮白底凸起，“象限图”深底白字，“30 待解问题”绿框。
- **同类按钮多种样子**：“展开全部技术体系”“各领域”“导出机会清单”同为次操作，却是 12/14 px 加 3 种边框色；02 的缩放按钮是 12 px。
- **两种主色**：设计稿 v2 右栏用绿色实底，03 “生成立项建议”用蓝色实底。
- **暖灰冷灰混用**：首页卡片文字是暖色 `--charcoal`（#37352f），边框是冷色 `--line-cool`（#e2e7ee）；领域分析未选中的分段按钮是暖色 `--steel`，所在轨道是冷色。令牌里暖、冷两套中性色并存，两页混用。
- **能点却像普通文字**：首页“各领域项目数”的 11 行，无底、无框、无 ›；工作台大卡片的“进入 →”只有 60% 不透明度。
- **下划线一词多义**：名词帮助（“立项年”“项目”）、“待补录”、“领域构成”、“怎么读”都用下划线，颜色却各不相同。
- **圆角 9 种**：0、4、6、7、8、10、12、16、999 px。
- **字号随 SVG 缩放**：8–11 px 的文字来自 SVG 随宽度缩放和手写字号。

## 3. 原则

1. **简单而不简陋**（用户原文 3）：分三层呈现，表层简单，深度功能不删：
   - **一眼**：结论、关键数字，不用操作；
   - **一点**：详情在右栏或右侧滑出，单击即得；
   - **深入**：02 技术谱系、资料库、工作台，入口清楚，不挤在表层。
2. **能点的一看就知道能点，不能点的绝不像能点**。
3. **同一种交互，全站同一种样子**：按钮、切换、可点内容、文字链接各一种写法，选中状态只有一种。
4. **颜色有角色**：主色只用于交互；数据用单色深浅，焦点用绿；状态色不做装饰；冷灰一套到底。
5. **关键信息不藏在悬停后面**：悬停只补充口径和明细。

图上节点（01 圆、02 节点、03 点）不属于以上六级，保持各自的图形暗示：手形光标、悬停光环；选中用绿色，表示数据焦点。

### 4.2 统一规则

- **选中只有两种**：L4 切换用白底凸起，其余一律用 L5 的选中样式。删除深底白字、绿框、深色边框三种写法。
- **主色唯一**：所有 L1 用 `--primary`。第三轮方案（收尾实施方案 §10）里右栏的绿色主按钮也改用 `--primary`；绿色只留给数据焦点。
- **下划线只有两种含义**：跳页链接用实线（悬停时出现），名词帮助用点线（常驻）。“待补录”改为琥珀色状态标签（`Pill tone="yellow"`），“领域构成”这类小标题不加下划线。
- **焦点**：所有可交互元素有 `:focus-visible` 主色外框；鼠标点击不出框。

### 4.3 配色

| 角色 | 令牌 | 规则 |
|---|---|---|
| 文字 | `--heading`；新增 `--text-2`（正文，建议 #3d4b5c）、`--text-3`（说明，建议 #6b7a8c）；`--muted-cool`（弱化） | 首页、领域分析不再使用暖灰 `--charcoal`、`--slate`、`--steel`、`--stone`。暖色一套留给对话、PDF 等工作区，本轮不改 |
| 结构 | `--canvas`、`--surface-cool`、`--selected-cool`、`--line-cool*`、`--page-cool` | 占画面绝大部分 |
| 交互 | `--primary`、`--primary-pressed`、`--link`、`--primary-soft` | 只用于能点的东西 |
| 数据 | `--bar`、`--bar-soft` 表示量；绿 #2e8b7a 表示焦点 | 多个领域同时比较时（轮播、02）才用各领域固定色，同一领域在各处颜色相同；01 只用单色加焦点绿 |
| 状态 | `--warn-*` 表示缺失、待补；`--danger-*` 表示错误 | 不做装饰 |
| 深色强调 | `--banner-1/2/3` | 每屏最多 1 块：首页轮播、领域分析要点 |

焦点绿目前写在 `domain-lens.css` 里，迁到 `globals.css` 作为令牌 `--focus-data`。

### 4.4 排版

- **字号只用 5 级令牌**：caption 12、body 14、emphasis 16、group 18、stat 28；首页轮播主数字可用 display 38。正文不小于 14 px；12 px 只用于刻度、单位、日期、口径浮层。
- **SVG 文字不随缩放变小**：图表用像素坐标绘制，或给文字设固定字号，不再出现 8–11 px。
- **圆角只用 3 种**：控件 6、条目 10、面板 16；胶囊形只用于 `Pill` 标签。
- **间距刻度**：4、8、12、16、24、32。区块之间 32，卡片内边距 16 或 20，同组元素之间 8 或 12。
- **区块标题一个样子**：编号（caption、`--muted-cool`）+ 标题（group）+ 一句说明（body、`--text-3`，可省）。
